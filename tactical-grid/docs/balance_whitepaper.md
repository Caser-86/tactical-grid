# Tactical Grid 数值平衡白皮书 v1.0

## 1. 设计目标

- **TTK（击杀所需回合）**：玩家单位击杀同级敌人需要 2-4 次攻击；敌人击杀玩家单位需要 3-5 次攻击。
- **风险与收益**：掩体、高地、侧翼必须产生显著战术差异。
- **职业差异**：突击兵近战高爆发、狙击手远程精准、重装兵抗线、医疗兵辅助、侦察兵机动。
- **成长曲线**：每章敌人强度提升约 15%，玩家通过升级和装备保持同步。

## 2. 核心公式

### 2.1 命中率

```
命中率% = base_hit
        + (attacker_height - target_height) * 10
        - cover_penalty
        - max(0, distance - optimal_range) * 8

cover_penalty:
  - 无掩体: 0
  - 半身掩体 (half): 20
  - 全身掩体 (full): 40
  - 软掩体 (soft): 15

最终命中率 clamp 在 [5%, 95%]
```

### 2.2 伤害

```
实际伤害 = max(base_damage - armor * 2, base_damage * 0.1)
暴击伤害 = 实际伤害 * crit_multiplier

armor: 目标护甲值
```

### 2.3 暴击率

```
crit% = base_crit + 0.05(高地打低地)
最终暴击率 clamp 在 [0%, 75%]
```

### 2.4 闪避

```
dodge% = base_dodge + terrain_bonus
  - 森林地形 +10%
最终闪避率 clamp 在 [0%, 40%]
```

## 5. 敌人数值缩放

```
敌人基础 HP = 职业基础 HP * (1 + 0.08 * floor_difficulty)
敌人基础伤害 = 武器平均伤害 * (1 + 0.06 * floor_difficulty)
```

## 6. 经济系统

### 6.1 收入来源

- 普通战斗胜利：100 CR
- 精英战斗胜利：200 CR
- BOSS 战斗胜利：500 CR + 装备
- 零伤亡奖励：+30%

### 6.2 消耗出口

- 商店物品：50-300 CR
- 装备升级：100 * (1.5 ^ 等级)
- 角色训练：200 CR / 次

## 7. 成长公式

### 7.1 角色升级

```
升级所需 EXP = 100 * level
每级属性提升：
  - HP +5
  - 命中 +1
  - 暴击 +0.5%
```

### 7.2 装备升级

```
升级成本 = base_cost * (1.5 ^ current_level)
属性提升 = base_stat * 0.1 * current_level
```
