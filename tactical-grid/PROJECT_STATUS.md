窗口化核查不等同于真人完成六场战术对局。平衡矩阵也明确标记为自动化目标，不冒充真人样本。扩展后的 18×14 首关仍需一次真人窗口化 QA（见发布前人工清单）。

## 当前发布阻断项

1. 第一章仍需真人完成三档难度的完整通关与数据记录。
2. 扩展后的 18×14 首关仍需一次窗口化真人 QA：验证 25-35 分钟时长、两轮上传、事件增援、可选资源收集与三星评级。
3. 仍需两小时长时运行、多分辨率、超宽屏、手柄和多硬件矩阵。
4. 音频技术检查已通过，但最终听感、响度和长循环验收仍需真人完成。
5. Windows 候选包尚未在全新 Windows 账户/设备上验收，也尚未代码签名。
6. 第二至第五章尚未达到第一章同等的内容、表现、平衡和 QA 标准。

## 下一阶段顺序

1. 执行扩展后首关的窗口化真人 QA，记录回合、存活、缓存与星级。
