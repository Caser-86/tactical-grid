## 已知发布阻断项

1. Godot 客户端尚未加载 `server/data/generated_maps/` 中的 30 张锁定地图；战斗仍使用独立的运行时随机地图逻辑。
2. 摧毁、窃取、护送、防守、潜入和暗杀等任务缺少完整目标实体或状态机。
3. 技能与物品按钮仍含固定调用，尚未按单位配置提供真实选择与目标流程。
4. 增援、陷阱、消音器、武器特殊效果和投掷范围效果尚未完整实现。
5. 战斗和测试退出仍报告 Godot RID、ObjectDB 或资源泄漏；腐坏存档测试也会产生预期外的解析错误日志。
6. 正式美术、动画和特效仍未完成接入；首轮程序化音乐和音效已接入菜单与战斗，但仍需最终混音与人工听感验收。
7. 音频资源已有来源、生成方式与 CC0 记录；历史图片仍缺少可发行的来源记录，已标为参考文件并被 Windows 导出排除。
8. Windows x64 构建与短时无窗口启动已验证；仍需在干净用户环境完成完整人工菜单、战斗和存档流程验收。

## 当前开发优先级

1. 将锁定地图导入客户端，并建立全地图加载测试。
2. 完成统一任务目标系统和对应交互实体。
3. 完成技能、物品、增援与自动对局稳定性。
4. 清除资源泄漏与错误输出，再验证完整菜单到结算流程。
5. 通过少量实装小样确定正式美术、动画和特效资源管线。
