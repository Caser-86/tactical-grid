## 已知发布阻断项

1. 菜单到任务选择、真实战斗输入、结算、基地升级、下一关生效和重启存档的人工端到端流程尚未完成验收。
2. 部分需要目标的技能仍以选中单位位置作为回退，尚未进入完整目标选择交互。
3. 武器特殊效果、陷阱、投掷范围效果和部分战术规则仍有简化或未完成分支。
4. 30 张锁定地图虽可加载和校验，但尚未逐关完成教学、事件编排、难度曲线与人工通关验收。
5. 第一章美术已接入，但仍需在不同分辨率、战场密度和所有状态下完成视觉可读性与动画/特效节奏 QA。
6. 音频仍需最终混音、音量平衡、循环衔接和人工听感验收。
7. 烟雾测试通过项计数已通过 `run_release_gate.ps1` 稳定为 1,607（连续三次完全一致）；发行前如修改测试函数需更新此基线。
8. Windows 导出预设使用临时产品信息、`0.1.0.0` 开发版本和默认 `icon.svg`；发行前需要最终品牌、版本、版权信息、重新导出和干净环境完整试玩。

## 当前开发优先级

1. 完成并记录真实玩家输入的首章端到端回归，优先覆盖新游戏、教程、首关、结算、基地、存档重启和第二关生效。
2. 实现技能、物品和目标对象的完整选择/确认/取消流程，移除自目标回退。
3. 补齐特殊战术规则并以自动测试和玩家场景验证覆盖。
4. 对 30 张锁定地图逐关策展、平衡、教学化并完成通关记录。
5. 完成视觉和音频 QA，随后重新构建 Windows 包并做干净环境发行验收。

## 证据边界

本页只陈述已由当前代码、资源引用或实际命令结果支持的事实。连续三次运行 `tests/run_release_gate.ps1` 均以退出码 0、通过 1,607、失败 0 结束，并显式捕获两条受控的备份恢复 warning；这不等同于人工全流程试玩或发行验收。历史导出包和服务端测试结果的具体时间以 [接管路线图](../docs/PROJECT_TAKEOVER_ROADMAP.md) 的验证记录为准。
