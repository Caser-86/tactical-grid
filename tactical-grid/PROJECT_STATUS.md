## 如何运行

### 后端
```bash
cd tactical-grid/server
npm install
npm run dev          # http://localhost:3000
```

### 生成地图
```bash
cd tactical-grid/server
npx tsx src/mapgen/cli.ts --size small --seed 12345 --visualize
```

### 运行测试
```bash
cd tactical-grid/server
npm test             # 29 个测试
```

### 前端
```
用 Godot 4.2 编辑器打开 client/project.godot
按 F5 运行
```
