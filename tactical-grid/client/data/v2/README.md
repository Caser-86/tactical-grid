# V2 数据目录

V2 的新地图、角色、敌人和平衡数据放在本目录及其子目录中。V1 数据只作为初始参考，不直接作为 V2 正式设计结论。

M1 当前内容基线：26×18 回声货运场，12 个敌人实体，按开场、路线分叉、吊桥、营救和撤离反制五个阶段分批激活，同时活跃敌人不超过 3 名。玩家先在路线分叉选择“维修摄像头”或“货柜突破”，再操作吊机打开两格通路；营救后东北直通线封锁，撤离狙击手进入搜索。事故记录室是清场后的可选奖励，可解锁侦察模块 B。锁定地图中的环境分区、装饰和路线后果均为确定性数据，不依赖运行时随机生成。

M1 关键地点：南侧货运坪（出生与初战）、路线分叉（8,14）、事故记录室（4,5）、吊机控制台（13,5）、中部侦察标记（16,8）、东北撤离台（23,2）。视觉矩阵覆盖 `start`、`route_split`、`record_room`、`gantry_open`、`rescue`、`evac_intercept`、`result` 七个阶段，验证命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/v2/run_m1_visual_matrix.ps1
```
