## 制作建议

1. 胶囊图需突出“战术网格 / 回合制 / 战棋”核心卖点
2. 截图应关闭性能监控器（PerformanceMonitor），使用最高分辨率
3. 所有商店图建议统一色调：深蓝/青绿科技感 + 高对比度角色
4. 上线前请确认图片无版权纠纷，字体/素材均已获得商用授权
