# 字体授权说明

## 当前使用字体

本项目当前使用 Godot Engine 内置默认字体作为占位字体。

## 上线前必须完成

1. 确认游戏中使用的所有字体（UI 字体、标题字体、剧情字体）均已获得商用授权。
2. 将授权文件或购买凭证保存到本目录下对应字文件夹中。
3. 在 `project.godot` 或主题配置中统一指定已授权字体，避免使用系统默认字体导致跨平台不一致。

## 推荐开源/免费商用字体（请自行核实最新授权条款）

- **思源黑体 / Source Han Sans** — Adobe/SIL Open Font License
- **Noto Sans CJK** — SIL Open Font License
- **得意黑 (Smiley Sans)** — SIL Open Font License
- **霞鹜文楷 (LXGW WenKai)** — SIL Open Font License

## 法律责任

字体侵权可能导致平台下架、索赔及声誉损失。请在正式上线前完成字体清查与授权归档。
