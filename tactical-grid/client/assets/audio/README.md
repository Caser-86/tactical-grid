# Tactical Grid Audio Sources

All WAV files in this directory are original procedural assets generated by
[`tools/generate_chapter1_audio.ps1`](../../tools/generate_chapter1_audio.ps1).
The generator synthesizes PCM waveforms directly and uses no recordings,
third-party samples, or external libraries.

- License: CC0 1.0, dedicated to the public domain by the project authors.
- Regeneration: run `powershell -ExecutionPolicy Bypass -File tools/generate_chapter1_audio.ps1` from `client/`.
- Scope: menu, battle, boss, outcome music, and high-frequency UI/combat feedback.

These are functional production placeholders only in the sense of a first audio pass:
they are real, playable, license-clear assets, and should be replaced by a curated
original score during final audio polish rather than by unverified external assets.
