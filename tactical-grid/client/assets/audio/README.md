# Tactical Grid Audio Sources

> status: Pre-redesign audio baseline
> updated: 2026-07-31

All WAV files currently in this directory are original procedural assets generated by
two PowerShell scripts:

1. [`tools/generate_chapter1_audio.ps1`](../../tools/generate_chapter1_audio.ps1) - base
   BGM and SFX set (menu, battle, boss, base, victory, defeat, UI, movement, combat,
   skill, item, turn and outcome feedback).
2. [`tools/generate_network_audio.ps1`](../../tools/generate_network_audio.ps1) - network
   and alert feedback set (scan, takeover, disable, overload, alert rise, camera reveal,
   turret reversal, beacon delay).

Both generators synthesize PCM waveforms directly and use no recordings, third-party
samples, or external libraries.

- License: CC0 1.0, dedicated to the public domain by the project authors.
- Regeneration:
  - Base set: `powershell -ExecutionPolicy Bypass -File tools/generate_chapter1_audio.ps1`
  - Network/alert set: `powershell -ExecutionPolicy Bypass -File tools/generate_network_audio.ps1`
- Current coverage: menu, battle, boss, outcome, UI/combat feedback, and network/alert
  facility feedback.
- Technical validation: `powershell -ExecutionPolicy Bypass -File tools/test_audio_assets.ps1`
  checks container format, sample rate, peak amplitude and content uniqueness for all
  34 WAV files.

## Polyphonic SFX Pool

`audio_manager.gd` maintains a 4-player `AudioStreamPlayer` pool
(`play_sfx_pooled`) so that concurrent sounds do not interrupt each other. All
network and alert SFX shortcuts (`sfx_network_scan`, `sfx_network_takeover`,
`sfx_network_disable`, `sfx_network_overload`, `sfx_alert_rise`,
`sfx_camera_reveal`, `sfx_turret_reversal`, `sfx_beacon_delay`) use the pooled
path so combat feedback remains audible while facility events fire.

These assets are license-clear technical and style baselines, not final audio approval. The
first chapter still needs layered combat music and phase stingers. New sounds must
be tested in real battle with concurrent playback, subtitles/reduced motion settings and
long-session loudness checks.
