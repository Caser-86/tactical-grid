从一个真实玩家"买游戏→安装→玩→通关→继续玩"的完整体验路径，逐环节检查是否有设计空白。

## 1. 启动流程设计

### 1.1 首次启动

```
启动游戏
  → 引擎 Splash
  → 开发者 Logo
  → 首次启动检测
    → 选择语言
    → 显示用户协议+隐私政策（需同意）
    → 选择难度（可随时改）
    → 创建存档（输入指挥官名字）
    → 新手教程提示（可跳过）
    → 进入教程第1关
```

### 1.2 非首次启动

```
启动游戏
  → Splash
  → 主菜单
    → 继续游戏（最近存档）
    → 读取存档
    → 新游戏
    → 设置
    → 创意工坊（后续）
    → 退出
```

### 1.3 版本更新检测

```yaml
version_check:
  on_launch: "对比本地版本与服务器最新版本"
  if_update_available:
    - "强制更新（重大漏洞）"
    - "可选更新（内容更新）"
    - "跳过（兼容版本）"
  changelog: "显示更新日志"
  asset_patch: "只下载变更资源"
```

## 3. 完整操作手感设计

### 3.1 操作反馈链

每个玩家操作必须有完整的反馈链：

```
玩家点击 → 按钮高亮 → 播放UI音效 → 执行动作 → 播放动画 → 显示结果 → 播放结果音效
```

### 3.2 操作延迟标准

| 操作 | 最大延迟 |
|------|---------|
| 点击选中 | 50ms |
| 移动范围显示 | 100ms |
| 路径预览 | 150ms |
| 攻击动画开始 | 200ms |
| 回合切换 | 500ms |
| 关卡加载 | 3s |

### 3.3 操作容错

| 场景 | 容错设计 |
|------|---------|
| 误点格子 | 显示"取消"按钮，1秒内可撤销 |
| 误移动 | 回合内可撤销移动（1次/回合）|
| 误攻击 | 攻击前显示确认弹窗（可在设置关闭）|
| 误结束回合 | 显示确认弹窗 |
| 误卖装备 | 显示确认弹窗 |
| 误拆解装备 | 显示确认弹窗 |

## 6. 云存档同步

### 6.1 同步策略

```
自动同步触发：
  - 关卡通关后
  - 基地操作后
  - 设置变更后
  - 游戏退出时
  
冲突解决：
  - 本地新 → 上传本地
  - 云端新 → 下载云端
  - 都有更新 → 让玩家选择
```

### 6.2 离线模式

```
离线可玩：
  - 全部主线
  - 全部支线
  - Roguelike
  - NG+
  
离线不可用：
  - 云存档同步
  - 遥测上报（缓存，上线后补报）
  - 每日挑战（需服务器生成）
```

## 8. 完整退出与暂停

### 8.1 暂停

```
战斗中按ESC/暂停键：
  → 弹出暂停菜单
    → 继续
    → 设置
    → 保存并退出
    → 放弃任务（确认弹窗）
```

### 8.2 自动暂停

```
触发自动暂停：
  - 失去焦点（切窗口）
  - 来电（移动端）
  - 系统休眠
  - 网络断开（不影响单机）
```

### 8.3 退出保存

```
退出游戏时：
  - 自动保存当前进度
  - 上传云存档
  - 记录最后位置
  - 下次"继续游戏"直接进入
```

```
崩溃 → 自动收集崩溃日志 → 下次启动提示"上次异常退出，是否恢复？"
  → 恢复到最近自动存档
```
