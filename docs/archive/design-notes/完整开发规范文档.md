## 1. 项目总览

### 1.1 游戏定位

| 项 | 内容 |
|---|------|
| 类型 | 平面格子回合制战术战棋 |
| 平台 | PC（Steam）+ 移动（iOS/Android） |
| 核心循环 | 目标驱动的掩体战术战 + 2AP 回合制 + 混合信息制 |

## 2. 核心玩法规则

### 2.1 战斗形态

**主线**：目标驱动的掩体战术战
**辅线**：地形推进 + 信息压制

```
目标点 → 逼迫玩家移动
掩体与可破坏物 → 制造局部攻防
地形差异 → 放大职业/兵种特性
```

### 2.2 回合结构

**全队回合制 + 单位行动点（2AP）**

| 行为 | 消耗 |
|------|------|
| 移动 | 移动点（基础 4-6 格） |
| 攻击/技能 | 1 AP |
| 冲刺 | 1 AP，移动点 +2 |
| 警戒/迎击/格挡 | 剩余 1AP 时可进入反应状态 |
| 攻击后移动 | 默认禁止，特职或技能解锁 |

### 2.3 坐标与移动

- **逻辑坐标**：方格，左上角 (0,0)，四邻接
- **斜线**：默认不计为移动；技能可穿越逻辑格对角
- **寻路**：A* 算法，成本矩阵移动（每职业一张成本表）
- **技能模板**：十字、扇形、直线、方块、环

### 2.4 高度系统（三层）

| 高度层 | 值 | 视野加成 | 命中加成 |
|--------|---|---------|---------|
| 低地 | 0 | 基础 | 基础 |
| 平台 | 1 | +1 格 | - |
| 制高点 | 2 | +2 格 | - |

- 高打低：命中 +10
- 低打高：命中 -10
- 攀高差 1 级免费；2 级需跳跃/坡道/技能

### 2.5 掩体系统

| 掩体类型 | 命中抗性 | 视线 |
|---------|---------|------|
| 半掩体 | +20 | 软遮蔽，穿透 -15 命中 |
| 全掩体 | +40 | 硬阻挡，完全挡直线视线 |
| 软遮蔽 | - | 穿透 -15 命中 |
| 硬阻挡 | - | 完全阻挡 |

### 2.6 信息制（混合制）

**已侦察敌人**：显示攻击目标、危险线、预计伤害区间
**未侦察区域**：显示"疑似巡逻扇区"或"声源风险圈"

### 2.7 胜利结构（混合胜）

```yaml
victory:
  primary: "完成主目标（激活终端/夺点/护送撤离）"
  secondary:
    - "零阵亡"
    - "资源箱 ≥ 1"
    - "回合数 ≤ 目标值"
  bonus_multiplier: 0.2
defeat:
  - "我方全灭"
  - "关键 NPC 死亡"
  - "回合时钟归零"
soft_fail:
  - "错过副目标 → 降评级继续"
```

**四种胜利路径**：速推、稳推、清图、牺牲换目标

### 2.8 敌人 AI

```
遭遇模板（决定敌群结构）
  + Utility AI（每回合按评分选动作）
  + Director（只管增援节奏与局面修正，不偷改命中率/血量）
```

| 敌人角色 | 行为权重主项 | 典型位置 |
|---------|-------------|---------|
| 盾卫/肉盾 | 抢掩体、封路、干扰 | 主路前沿 |
| 狙击/炮手 | 取高地、压后排 | 高地或远端窗台 |
| 突击/刺客 | 绕侧、逼撤离、切奶妈 | 侧翼或暗门 |
| 支援/召唤 | 复活、护盾、召唤障碍 | 中后排 |
| 目标守卫 | 围绕任务点不远离 | 主目标周边 |

## 4. 地图自动生成系统

### 4.1 设计目标

**玩家零设计**：调用生成器 → 自动产出可玩地图 → 导入游戏即可用。

### 4.2 三档地图规格

| 级别 | 尺寸 | 局长 | 出生区深度 | 主战区宽度 | 单位数 | 目标数 |
|------|------|------|-----------|-----------|--------|--------|
| 小图 | 10×8 | 8-12 分钟 | 2-3 格 | 5-6 格 | 4 vs 5 | 1+0 |
| 中图 | 14×10 | 12-18 分钟 | 3-4 格 | 7-8 格 | 5 vs 7 | 1+1 |
| 大图 | 18×12 | 18-25 分钟 | 4-5 格 | 9-11 格 | 5-6 vs 9-10 | 1+2 |

### 4.3 地图五层结构

```
Layer 1: BaseTerrain  - 地形层（plain/road/forest/sand/highland/water）
Layer 2: Blocker      - 阻挡层（wall/crate/poison/bridge）
Layer 3: Vision       - 视野层（soft_cover/hard_block）
Layer 4: Objects      - 对象层（spawn/terminal/evac/resource/enemy）
Layer 5: Script       - 脚本层（trigger/condition/action）
```

### 4.4 生成器输入参数

```json
{
  "size": "small|medium|large",
  "seed": 12345,
  "theme": "warehouse|city_ruins|mountain_fort|forest_camp",
  "mission_type": "extract|escort|destroy|defend",
  "difficulty": 1,
  "rules": {
    "min_routes": 2,
    "main_target_reachable": true,
    "no_highland_dominance": true,
    "reinforcement_safe_distance": 5,
    "destructible_cover_ratio": [0.35, 0.50]
  }
}
```

### 4.5 生成器算法流程

```
1. 初始化网格（全 plain）
2. 生成主路径（出生区 → 主目标区），至少 2 条
3. 沿路径铺设 road
4. 在路径外填充 forest/sand/water（按 theme 权重）
5. 放置 highland 平台（每 25 格 ≤ 3 个制高点）
6. 放置 wall/crate 掩体（全掩体密度 12%-18%）
7. 标记可破坏物（35%-50% 的掩体）
8. 放置对象层：
   - 玩家出生点（出生区深度内）
   - 敌人出生点（距玩家 ≥ 5 格）
   - 主任务点（路径交汇处）
   - 撤离点（远端）
   - 资源点（侧路）
9. 生成脚本层（增援触发、事件）
10. 校验：
    - 连通性（A* 全图可达）
    - 公平性（最短路差 ≤ 2）
    - 安全性（首回合不可贴脸）
    - 密度（掩体/高地/资源 符合阈值）
11. 失败则重新生成（同 seed 可复现）
12. 输出 Tiled JSON + 游戏数据 JSON
```

### 4.6 输出格式（Tiled 兼容 JSON）


### 4.7 策展式随机（高级模式）

将地图拆分为 parcel 模块（5×4 或 6×5）：

| 模块类型 | 内容 | 约束 |
|---------|------|------|
| 出生区 | 玩家出生点 + 安全缓冲 | 距敌人 ≥ 5 格 |
| 主路 | 道路 + 掩体 + 1 个分叉 | 必须连通目标 |
| 侧路 | 资源点 + 隐蔽路径 | 至少 2 条可行路线 |
| 目标区 | 主任务点 + 守卫 | 高地不独占 |
| 装饰插槽 | 植被/碎片/贴花 | 不影响逻辑 |

```
生成：随机选模块 → 拼接 → 接缝校验 → 整体校验 → 输出
```

### 4.8 大模型辅助生成（可选）

## 5. 美术资源 AI 生成方案

### 5.1 美术风格定调

**主风格**：低多边形半写实（Low Poly Semi-Realistic）
**理由**：兼顾 PC/移动性能、远近景识别、颜色分层、UI 叠加

**视觉句法**（每种功能元素固定视觉规则）：

| 功能元素 | 视觉规则 |
|---------|---------|
| 可破坏物 | 裂纹或耐久色条 |
| 半掩体/全掩体 | 明确轮廓高度差 |
| 高地 | 轮廓线与投影差 |
| 危险格 | 动态边缘闪烁（1.2-1.8Hz） |
| 任务点 | 独特 silhouette + 小幅循环动效 |

**配色规范**：1 主色 + 1 辅色 + 1 功能对比色

### 5.2 资产清单与生成方案

#### 5.2.1 角色立绘/肖像

| 资产 | 数量 | 规格 | 生成方式 |
|------|------|------|---------|
| 玩家职业肖像 | 5 张 | 512×512 PNG，透明背景 | 文生图 + 去背 |
| 敌人类型肖像 | 8-10 张 | 512×512 PNG | 文生图 + 去背 |
| NPC 肖像 | 3-5 张 | 512×512 PNG | 文生图 + 去背 |

**Prompt 模板**：
```
low poly semi-realistic character portrait, [职业名],
[faction_color] uniform, clean silhouette,
game asset, transparent background, 512x512,
top-down tactical RPG style, flat lighting
```

**风格统一**：训练一个低多边形半写实风格 LoRA，所有角色走同一 prompt 模板。

#### 5.2.2 Tile 贴图集

| 资产 | 数量 | 规格 | 生成方式 |
|------|------|------|---------|
| 地形 tile | 10 种 × 4 变体 | 64×64 PNG | 方案见下 |
| 障碍物 tile | 6 种 × 2 变体 | 64×64 PNG | 方案见下 |
| 高地过渡 tile | 8 种 | 64×64 PNG | 程序生成 |

**Tile 生成方案（三选一）**：

**方案 1（推荐·保底）**：使用开源免费 tileset
- Kenney.nl（CC0 授权，低多边形风格齐全）
- itch.io 免费 pack
- OpenGameArt.org
- AI 只生成角色和 UI

**方案 2（纯 AI）**：
```
1. 文生图生成单 tile 素材（64×64）
2. ImageMagick 脚本做边缘羽化 + 色彩统一
3. 训练 LoRA 保证风格一致
4. 切片为 tileset PNG
```

**Prompt 模板**：
```
seamless tileable texture, [terrain_type],
low poly, top-down view, 64x64,
game tile, clean edges, [主色调],
flat shading, no shadow
```

**方案 3（混合）**：AI 生成 → 脚本后处理
```python
# art_pipeline/process_tiles.py
1. 加载 AI 生成的原始图
2. 缩放到 64×64
3. 边缘羽化（2px）
4. 色彩归一化（匹配主色板）
5. 生成法线贴图（可选）
6. 拼接为 tileset.png
7. 输出 Tiled tileset 定义 JSON
```

#### 5.2.3 UI 图标

| 资产 | 数量 | 规格 | 生成方式 |
|------|------|------|---------|
| 职业图标 | 5 个 | 64×64 SVG/PNG | 文生图 + 矢量化 |
| 地形图标 | 10 个 | 32×32 PNG | 文生图 |
| 功能图标 | 15 个 | 32×32 PNG | 文生图 |
| 状态图标 | 8 个 | 32×32 PNG | 文生图 |

**Prompt 模板**：
```
flat icon, [icon_name], minimal,
monochrome [color], 64x64,
game UI, no background, svg style
```

#### 5.2.4 特效素材

| 资产 | 数量 | 规格 | 生成方式 |

```gdscript
# core/combat_formulas.gd
class_name CombatFormulas

static func calculate_hit(base_hit: int, attacker_height: int, target_height: int, cover: String) -> float:
    var hit = base_hit
    hit += (attacker_height - target_height) * 10  # 高度差
    match cover:
        "half": hit -= 20
        "full": hit -= 40
        "soft": hit -= 15
    return clamp(hit, 5, 95) / 100.0

static func calculate_damage(base_damage: int, hit: bool, critical: bool) -> int:
    if not hit: return 0
    var dmg = base_damage
    if critical: dmg *= 1.5
    return int(dmg)
```

### 8.4 地图生成器（核心）

```typescript
// mapgen/generator.ts
interface GenerateParams {
  size: 'small' | 'medium' | 'large';
  seed: number;
  theme: string;
  mission_type: string;
  difficulty: number;
}

interface MapData {
  map_id: string;
  seed: number;
  size: { width: number; height: number };
  layers: { base_terrain: number[][]; blocker: number[][]; vision: number[][]; height: number[][] };
  objects: MapObject[];
  scripts: MapScript[];
  victory: VictoryConfig;
  validation: ValidationResult;
}

function generateMap(params: GenerateParams): MapData {
  const sizeConfig = SIZE_PRESETS[params.size];
  const rng = new SeededRandom(params.seed);
  
  // 1. 初始化网格
  let grid = initGrid(sizeConfig);
  
  // 2. 生成主路径
  grid = generateMainPaths(grid, sizeConfig, rng);
  
  // 3. 填充地形
  grid = fillTerrain(grid, params.theme, rng);
  
  // 4. 放置高地
  grid = placeHighlands(grid, sizeConfig, rng);
  
  // 5. 放置掩体
  grid = placeCovers(grid, sizeConfig, rng);
  
  // 6. 放置对象
  const objects = placeObjects(grid, params.mission_type, sizeConfig, rng);
  
  // 7. 生成脚本
  const scripts = generateScripts(params.mission_type, rng);
  
  // 8. 校验
  const validation = validateMap(grid, objects);
  
  if (!validation.passed) {
    return generateMap(params);  // 重新生成
  }
  
  return { map_id, seed, size, layers, objects, scripts, victory, validation };
}
```
