# 01 · API 接口规范

## 通用规范

### 请求头
```
Content-Type: application/json
Authorization: Bearer <JWT_TOKEN>
X-Client-Version: 1.0.0
X-Platform: web|ios|android|windows
X-Device-Id: <设备唯一标识>
```

### 统一响应格式
```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": 1718620800000,
  "request_id": "req-uuid-xxxx"
}
```

### 错误码表

| 错误码 | 含义 | HTTP |
|--------|------|------|
| 0 | 成功 | 200 |
| 1001 | 参数错误 | 400 |
| 1002 | 未认证 | 401 |
| 1003 | 无权限 | 403 |
| 1004 | 资源不存在 | 404 |
| 1005 | 资源冲突 | 409 |
| 2001-2003 | 用户相关错误 | 4xx |
| 3001-3002 | 存档相关错误 | 4xx |
| 4001-4002 | 地图生成错误 | 5xx/422 |
| 5001-5003 | 服务器错误 | 5xx |
| 9001 | 限流 | 429 |

# 02 · 资产命名与目录规范

## 美术资产命名

### 角色立绘
```
char_{角色ID}_{表情}.png
示例：char_alpha_normal.png
      char_alpha_happy.png
      char_alpha_serious.png
```

### 角色立绘尺寸
- 肖像：512×512 px，PNG，透明背景
- 全身立绘：1024×1536 px，PNG，透明背景

### Tile 贴图
```
tile_{地形ID}_{变体编号}.png
示例：tile_plain_01.png
      tile_road_01.png
      tile_forest_01.png
      tile_wall_01.png
```
- 尺寸：64×64 px，PNG
- 无缝拼接，边缘对齐

### 敌人贴图
```
enemy_{敌人ID}.png
示例：enemy_drone_scout.png
      enemy_sentry_basic.png
```
- 尺寸：128×128 px，PNG，透明背景

### 武器图标
```
icon_weapon_{武器ID}.png
示例：icon_weapon_shotgun.png
```
- 尺寸：64×64 px，PNG，透明背景

### 物品图标
```
icon_item_{物品ID}.png
示例：icon_item_med_kit.png
```
- 尺寸：64×64 px，PNG，透明背景

### 技能图标
```
icon_skill_{技能ID}.png
示例：icon_skill_asslt_dash_strike.png
```
- 尺寸：64×64 px，PNG，透明背景

### UI 图标
```
icon_ui_{功能名}.png
示例：icon_ui_move.png
      icon_ui_attack.png
      icon_ui_overwatch.png
```
- 尺寸：48×48 px，PNG，透明背景

### 特效序列帧
```
fx_{效果名}_{帧号:03d}.png
示例：fx_explosion_001.png
      fx_explosion_002.png
      fx_explosion_008.png
```
- 尺寸：128×128 px，PNG，透明背景

## 音频资产命名

### BGM
```
bgm_{场景}_{编号}.ogg
示例：bgm_menu_01.ogg
      bgm_battle_small_01.ogg
      bgm_battle_medium_01.ogg
      bgm_battle_large_01.ogg
      bgm_boss_01.ogg
      bgm_victory_01.ogg
      bgm_defeat_01.ogg
```
- 格式：OGG Vorbis
- 采样率：44100 Hz
- 循环：无缝

### 音效
```
sfx_{类别}_{描述}.wav
示例：sfx_ui_click.wav
      sfx_ui_hover.wav

      sfx_combat_shotgun.wav
      sfx_combat_explosion.wav
```

- 格式：WAV

### 语音
```
voice_{角色ID}_{事件}_{编号}.ogg
示例：voice_alpha_select_01.ogg
      voice_alpha_attack_01.ogg
      voice_alpha_hurt_01.ogg
```

# 05 · CI/CD 配置

## GitHub Actions 完整配置

```yaml
# .github/workflows/ci-cd.yml
name: CI/CD Pipeline

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  # 1. 代码检查
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
      - run: cd server && npm ci && npm run lint
      - run: cd client && godot --headless --script lint.gd

  # 2. 单元测试
  test:
    runs-on: ubuntu-latest
    needs: lint
    steps:
      - uses: actions/checkout@v3
      - run: cd server && npm ci && npm test
      - run: cd server && npm run test:coverage
      - uses: codecov/codecov-action@v3

  # 3. 地图生成器压力测试
  mapgen-stress:
    runs-on: ubuntu-latest
    needs: test
    steps:
      - run: cd server && npm run test:mapgen:stress

  # 4. 构建 Godot 前端
  build-web:
    runs-on: ubuntu-latest
    needs: [test, mapgen-stress]
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v3
      - name: Build Godot Web
        run: |
          godot --headless --export-release "Web" ./build/web/index.html
      - uses: actions/upload-artifact@v3
        with:
          name: web-build
          path: ./build/web

  build-windows:
    runs-on: ubuntu-latest
    needs: [test, mapgen-stress]
    if: github.ref == 'refs/heads/main'
    steps:
      - run: godot --headless --export-release "Windows" ./build/windows/game.exe
      - uses: actions/upload-artifact@v3
        with:
          name: windows-build
          path: ./build/windows

  # 5. 构建后端
  build-server:
    runs-on: ubuntu-latest
    needs: test
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v3
      - run: cd server && npm ci && npm run build
      - uses: actions/upload-artifact@v3
        with:
          name: server-build
          path: ./server/dist

  # 6. 部署
  deploy-staging:
    runs-on: ubuntu-latest
    needs: [build-web, build-server]
    if: github.ref == 'refs/heads/develop'
    steps:
      - name: Deploy to Staging
        run: |
          # 部署后端到 CloudBase
          tcb deploy --env staging
          # 部署前端到 EdgeOne
          edgeone deploy ./build/web --env staging

  deploy-production:
    runs-on: ubuntu-latest
    needs: [build-web, build-server]
    if: github.ref == 'refs/heads/main'
    steps:
      - name: Deploy to Production
        run: |
          tcb deploy --env production
          edgeone deploy ./build/web --env production
        environment:
          name: production
          url: https://tactical-grid.com
```

# 09 · 风险评估与应急预案

## 开发风险

| 风险 | 概率 | 影响 | 预防 | 应急 |
|------|------|------|------|------|
| 地图生成器产出质量不稳定 | 中 | 高 | 1 万张压力测试 | 预置手工地图保底 |
| AI 美术风格不统一 | 高 | 中 | 训练 LoRA + 风格检查脚本 | 使用开源 tileset 保底 |
| Godot 性能不达标 | 低 | 高 | 早期性能测试 | 降级渲染、减少粒子 |
| PvP 同步回合制实现复杂 | 高 | 中 | 早期技术验证 | PvP 延后上线，先单机 |
| AI 代码质量不稳定 | 中 | 中 | Code review + 测试 | 人工重构关键模块 |

## 上线风险

| 风险 | 概率 | 影响 | 应急 |
|------|------|------|------|
| 服务器过载 | 中 | 高 | 自动扩容 + 限流 |
| 存档损坏 | 低 | 极高 | 多重备份 + 校验和 |
| 外挂 | 高 | 高 | 服务端校验 + 举报系统 |
| 差评轰炸 | 中 | 高 | 快速响应 + 社区沟通 |
| 支付系统故障 | 低 | 高 | 备用支付通道 |

## 运营风险

| 风险 | 应急 |
|------|------|
| 玩家流失 | 数据分析 → 内容更新 |
| 平衡性问题 | 自动对局 bot 持续监控 → 热更新 |
| 赛事作弊 | 人工审核 + 回放检查 |
| 社区危机 | 24h 响应预案 |
