# 历史文档归档

本目录保存仍有追溯价值、但不再作为当前开发依据的材料。归档不表示内容错误；它表示其中的版本、路径、范围、完成状态或工具假设已经不再可靠。

## 目录

| 目录 | 内容 | 使用限制 |
|---|---|---|
| [design-notes/](design-notes/) | 早期完整设计、扩展系统、角色/装备方案和内容设想 | 仅作灵感与历史参考，不构成首发承诺 |
| [initial-audit/](initial-audit/) | 早期一次性审计脚本和输出 | 路径、版本和结论已过时，不作为当前验证命令 |

当前开发请从 [文档索引](../README.md) 开始，并优先遵循 [接管路线图](../PROJECT_TAKEOVER_ROADMAP.md)。
