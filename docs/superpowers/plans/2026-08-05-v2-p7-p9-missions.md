# Tactical Grid V2 P7-P9 Missions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 M1 和共享内容通过硬门后完成 M2-M6、四人解锁、四选三、两档难度、Boss、结局、存档继续和任务重玩。

**Architecture:** 每关使用一份 schema v3 锁定地图和数据驱动的 `V2MissionFlow` 配置；独特机制通过具名 interaction handler 或 mission rule 实现，不在 BattleController 添加按关卡 ID 的大型分支。每关先通过单关 E2E，再加入连续章节 E2E 和真人样本。

**Tech Stack:** Godot 4.7.1、GDScript、JSON 锁定地图、V2 共享角色/敌人/环境、Godot headless E2E。

## Global Constraints

- 依赖 M114 和 A01-A14 全部通过。
- M2-M3 同时最多 3 名普通敌人，M4-M6 同时最多 4 名；不存在无限增援。
- M2 营救狙击、M3 营救重装；M4-M6 从四名角色选择三名，任意合法编队都能完成主线。
- 每关一个一句话主目标、两条主要路线、一个可选房间、一个独特地标。
- M2-M4 每关只引入一个主要新概念；M5-M6 不再显示基础教学弹窗。
- 每关地图、机制、进度、E2E 和平衡分开提交；不同时重构 BattleController。
- 每个任务先写失败测试，结束时运行当前关 E2E 和完整 V2 门。
