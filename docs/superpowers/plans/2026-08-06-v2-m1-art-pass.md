# V2 M1 Art Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the V2 M1 graybox into a visually readable first-chapter slice without changing V1.

**Architecture:** Keep `ArtCatalog` as the single runtime lookup layer. Improve the V2 battle presentation in `battle_controller.gd` and `v2_battle_controller.gd` without changing mission rules. Add or revise only V2 runtime assets and register every asset in the existing manifest.

**Tech Stack:** Godot 4.7.1, GDScript, PNG with transparent backgrounds, existing V2 `ArtCatalog`, PowerShell test gate, generated visual snapshot matrix.

## Global Constraints

- V2 resources live under `tactical-grid/client/assets/generated/chapter1/runtime`.
- V2 runtime must not read V1 worktree paths or V1 save data.
- Keep the existing Echo Yard blue/orange industrial style.
- Use existing legal/generated assets first; new generated assets require manifest entries.
- Every visual change must be verified at both 1280x720 and 1920x1080.
