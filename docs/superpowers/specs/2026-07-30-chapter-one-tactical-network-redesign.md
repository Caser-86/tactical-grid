## 1. 产品决策

第一章的正式核心体验为：

> 观察已侦测敌人的行动意图，争夺连接设施的战术节点，再利用被接管的摄像头、门、炮塔、电力和增援信标改变战局。

这不是独立黑客小游戏。终端、设施、战争迷雾、敌人意图、警戒和职业能力围绕同一条战斗循环工作，玩家不管理新的货币、卡牌、密码或复杂网络面板。

第一章完成后，玩家应能说：

> 我不是只在格子上换血。我先获取信息，再控制战场，让敌人的计划失效。

## 2. 体验原则

- 简洁：普通回合通过直接点击完成，屏幕同时最多突出三个主要选择。
- 清楚：已知威胁、行动代价、设施结果和下一警戒后果可预览。
- 有趣：每个遭遇至少有一次改变战场规则的机会。
- 紧张：未知区域与事件警戒形成压力，不使用普遍硬倒计时。
- 可制作：先做一个 M1 正式遭遇区，通过真人门后再批量生产。

## 3. 明确非目标

- 独立实时潜行模式。
- 节点连线解谜或密码小游戏。
- 战斗内黑客点数、能量、卡牌或连击槽。
- 逐回合回退、完整战斗快照和刷随机数读档。
- 两回合倒地救援、永久死亡和伤员养成。
- 升降桥、移动平台和大规模可破坏场景。
- 程序随机生成主线地图。
- 无限增援、词条装备和随机掉落。
- 第一章同时推出五名以上可部署角色。

## 4. 回合结构

玩家单位拥有独立移动额度和 2AP。移动不应被错误描述为一定消耗 AP；攻击、技能、物品、警戒和网络操作按现有规则消耗 AP。

每回合形成五步：

1. 观察：查看正在观察的敌人意图、设施状态和警戒后果。
2. 选威胁：确定最需要处理的一至两个目标。
3. 行动：移动、射击、能力或节点操作。
4. 改写：利用位移、设施和视野改变敌人计划。
5. 承诺：结束回合前显示预计受伤单位和即将发生的事件。

普通敌方回合应在 8 秒内完成。只有新敌人、重伤、设施反转和任务阶段变化获得短聚焦。

## 5. 输入与 HUD

### 5.1 输入

- 左键单位：选择。
- 左键安全可达格：显示路径、移动消耗、掩体和风险后直接移动。
- 悬停敌人：显示伤害、掩体和状态结果。
- 左键可攻击敌人：执行当前预览的主武器攻击。
- 左键设施：显示不超过三个上下文操作。
- 右键：取消当前操作。
- `Tab`：下一名可行动队员。
- `Space`：结束回合，保留现有肌肉记忆。
- `G`：切换战术网络连线。
- `Home`：聚焦当前单位。
- `Esc`：暂停。
- 战场总览使用另一个可重映射按键，不与 `Tab` 冲突。

安全移动和普通主武器攻击不二次确认。会触发反应射击、警戒或明确任务风险的行动出现一次确认。

### 5.2 HUD

- 顶部左侧：回合和阶段。
- 顶部中央：一句当前目标。
- 顶部右侧：警戒等级与下一具体后果。
- 右侧：选中单位或敌人的紧凑信息卡，无对象时折叠。
- 底部：当前单位的移动、主武器、两个能力、一个物品、警戒和结束回合。
- 地图内：意图、设施状态、风险格和目标。

无选择状态必须告诉玩家下一步，例如“选择青色队员”。移动范围叠层不得遮蔽地形和单位辨识。

## 6. 战术网络

### 6.1 节点和设施

每个战术区域有一个节点，连接一至三个设施：

- 摄像头：观察区域并公开敌方意图。
- 安全门：开启捷径或锁住敌方路线。
- 炮塔：改变阵营并覆盖固定射界。
- 电力导管：产生短时危险区或关闭区域电力。
- 增援信标：延迟、改向或取消一批增援。

设施只有敌方、玩家、中立、损坏四种状态，直接显示在地图上。

### 6.2 三个操作

| 操作 | 结果 | 代价 |
|---|---|---:|
| 接管 | 节点和连接设施持续为玩家服务 | 1AP |
| 禁用 | 关闭一个危险设施，不改变整个节点 | 1AP |
| 过载 | 立即产生强效果，设施永久损坏并提高警戒 | 1AP |

界面只显示当前节点真实支持的操作。

### 6.3 接管脉冲

玩家第一次接管节点时，立即免费触发一次连接设施：

- 摄像头立即扫描相邻区域。
- 炮塔立即进行一次转向射击。
- 门控立即开启捷径或锁住追兵。
- 电力立即改变危险区。
- 信标立即取消或改向一批待命增援。

每个节点整场只触发一次接管脉冲，不能反复夺回刷收益。

### 6.4 职业关系

所有角色都能相邻接管，避免任务因特定职业失能而锁死。

- 突击：快速抢点，把敌人推入设施射界。
- 狙击：借受控摄像头共享视野和标记。
- 重装：低代价过载并保护节点附近队友。
- 侦察：可接入 3 格内且有视线的节点。

“静默禁用”不作为侦察兵初始能力，后续可作为升级，避免基础能力定义含糊。

## 7. 战争迷雾与意图

| 信息状态 | 显示内容 |
|---|---|
| 未探索 | 不显示地形细节、单位和设施连接 |
| 已记录 | 显示地形和发现过的设施，不显示实时单位 |
| 正在观察 | 显示单位、朝向、意图和实时设施状态 |

角色视野、受控摄像头和侦察能力产生“正在观察”。离开视野后退回“已记录”，保留明确标为过时的最后已知敌人位置。

敌方意图只对正在观察的敌人显示：

- 普通敌人：目标格、目标单位和行动类型。
- 精英敌人：行动类型和大致方向，隐藏一个细节。
- Boss：阶段行动和危险区域，不公开全部连锁结果。

新敌人首次进入视野时只移动、警戒或准备能力，不在没有预警的情况下立即造成致命伤害。

## 8. 警戒

警戒由事件提升，不默认每回合增长：

- 摄像头完整识别玩家。
- 通讯单位逃到增援信标。
- 使用高噪声爆炸物。
- 过载节点。
- 特定任务事件。

| 等级 | 具体后果 |
|---|---|
| 0 潜伏 | 初始巡逻和守卫 |
| 1 搜索 | 巡逻改线，摄像头转向加快 |
| 2 封锁 | 部分门锁定，一组增援待命 |
| 3 猎杀 | 精英激活，撤离或主要目标改变 |

HUD 显示“下一次警报：东门增援进入”等具体后果，不只显示抽象进度条。

## 9. 战斗、失能与失败

- 半掩体可把正常命中降为擦伤，但普通攻击不应频繁完全无效。
- 全掩体正面大幅削弱或阻挡射击。
- 侧翼、高地、标记和设施照明提供稳定收益。
- 暴击主要来自玩家创造的条件，不主要依靠随机概率。
- 角色 0 HP 后本任务失去行动能力。
- 第一章没有永久死亡。
- 单人失能不立即失败；全队失能、关键目标被摧毁或明确任务条件发生时失败。
- 任务可从最近完成的遭遇区检查点重试，不提供逐回合回退。

## 10. 角色与敌军

### 10.1 四名正式角色

| 职责 | 战术身份 | 视觉轮廓 |
|---|---|---|
| 突击 | 突破、推离、抢点 | 中型宽肩、短枪、青色前臂灯 |
| 狙击 | 标记、封线、远程处决 | 细长轮廓、长枪、白色光学镜 |
| 重装 | 压制、保护、过载 | 大体型、背部弹药、橙色肩甲 |
| 侦察 | 揭露、侧翼、远程接入 | 低姿态、天线背包、绿色腿甲 |

颜色只是辅助。灰度下仍必须根据体型、武器、姿态和背部装备区分。

每名角色只携带一个被动、两个主动能力和一个物品。医疗兵作为基地 NPC 或后续章节候选，不属于第一章四名正式部署角色。

### 10.2 五种敌军职责

| 敌人 | 行为 | 玩家应改变什么 |
|---|---|---|
| 巡逻哨兵 | 守点、射击、寻找掩体 | 学习基础威胁 |
| 侦察无人机 | 扫描、标记、提高警戒 | 优先处理信息威胁 |
| 盾卫 | 保护后排和节点 | 侧翼、推离或过载 |
| 协议工程师 | 夺回节点、启动增援 | 打断任务行为 |
| 猎手 | 沿未控制路线侧翼追击 | 避免过度分散 |

难度优先改变编组、入口、意图隐藏和警戒后果，不大量增加生命和敌人数。

## 11. 地图和第一章六关

每张地图由三至四个连续遭遇区组成。每区必须有主要威胁、战术节点、至少两种处理方案、影响后续的设施结果和视觉地标。

已确认安全区域可快速集合，发现新敌人、视野或警报时停止。任何连续四回合没有新信息、交互或威胁变化的路线都应缩短。

| 任务 | 编制与规模 | 核心变化 | 时长 |
|---|---|---|---:|
| M1 回声失联 | 单人开场，救出侦察后双人；约 22×16；7-9 敌人，最多 3 活跃 | 摄像头节点揭示被困队员并改变撤离路线 | 15-20 分钟 |
| M2 熄灯协议 | 三人，重装加入 | 电力、炮塔、盾卫，两条供电路线 | 20-25 分钟 |
| M3 断轨营救 | 三人 | 道岔、移动目标、工程师，首个明确倒计时 | 20-25 分钟 |
| M4 囚笼密钥 | 四选三，侦察加入 | 多入口监区、门控网络、临时盟友 | 25-30 分钟 |
| M5 反向猎杀 | 四人 | 敌人反夺节点，网络中断后重建控制 | 25-30 分钟 |
| M6 零号终端 | 四人 | 三节点 Boss：护盾、污染、四回合熔毁终局 | 30-35 分钟 |

第一章目标战斗时长约 2.3-2.8 小时；加基地、剧情和合理重试约 3.5-4.5 小时。该目标必须通过真人数据验证。

## 12. 评价、成长与兼容

结算展示三个独立徽章：

- 任务：完成主目标。
- 情报：完成信息或网络可选目标。
- 小队：完成该关特有战术挑战。

内部继续使用现有整数 `stars` 字段：

- 3：三项完成。
- 2：主目标加一个可选项。
- 1：只完成主目标。

这样保留现有存档、解锁和结算兼容性，UI 不再称为限回合三星。

基地流程控制在 2-4 分钟：

1. 查看任务情报和已知节点。
2. 选择队员、武器和一个物品。
3. 参战角色在两个改变用法的升级中选一个。

## 13. 美术、音频与可访问性

优先复用四套环境包、现有单位源图、肖像、HUD、目标物和程序化音频。正式新增范围：

- 四名玩家角色轮廓和职业色饰。
- 协议工程师、猎手两套敌人。
- 节点四状态和五类设施图标。
- 敌方意图、网络、风险和警戒图形语言。
- 接管、禁用、过载和设施反转 VFX。
- 六关各一个主地标。
- 正式简体中文 UI 字体。
- 至少 8 个网络/警戒 SFX、3 个音乐层和阶段短句。

先完成一个 M1 遭遇区小样，接入 Godot 后检查透明、尺寸、切图、导入、缩放、动画、音频并发、灰度和色觉缺陷模式，再批量制作。

## 14. 系统边界

- `TacticalNetworkState`：节点、连接、设施控制和接管脉冲。
- `VisibilityState`：未探索、已记录、正在观察和最后已知单位。
- `EnemyIntentState`：根据可观察信息生成公开意图。
- `AlertState`：接收具名事件并发布下一后果。
- `MissionObjectiveState`：任务阶段、主目标和可选目标的唯一权威。
- `BattleController`：协调，不保存规则副本。
- HUD：显示状态、发送请求，不自行推断规则。

行动采用查询/预览/校验/提交。引入稳定实体 ID、单一可注入 RNG 和版本化地图模式。客户端锁定地图是唯一正式关卡权威。

## 15. 验收

### 可理解性

- 新玩家五分钟内完成选择、移动、攻击、接管和结束回合。
- 玩家能指出当前最危险的已知敌人。
- 玩家能解释接管、禁用和过载。
- HUD 同时突出不超过三个主要任务信息。

### 趣味性

- 每区至少两种有效处理方案。
- 每关至少两次设施操作明显改变战局。
- M1 至少出现一次接管后立即改变决策的时刻。
- Boss 三阶段要求不同决策。

### 表现和节奏

- M1 首次 15-20 分钟。
- 普通敌方回合不超过 8 秒。
- 操作反馈在 0.5 秒内开始。
- 教程使用短提示和局部高亮。
- 1280×720 不出现地图挤在顶部、下方大面积黑区。
- 角色、敌人、目标、设施和危险区在 720p 可分辨。

### 真人测试

- 至少 3 名首次玩家完成 M1。
- 一名玩家连续完成第一章。
- 每关、每难度至少 3 个样本。
- 记录时长、回合、失能、重试、警戒峰值、节点使用和放弃原因。
- 至少一次 1280×720 和一次 1920×1080 全流程。

自动化证明规则稳定，不能替代趣味性证据。

## 16. 实施顺序

1. 修复 720p 镜头构图、输入冲突、原始对话 ID 和无选择状态。
2. 统一目标状态、行动预览/提交、稳定 ID、RNG 和地图模式。
3. 实现战争迷雾、观察状态、AI 计划和公开意图。
4. 完成一个节点、摄像头、门、炮塔、电力、信标的网络垂直切片。
5. 重建 M1，完成真实输入 E2E 和 3 名新玩家门。
6. M1 获批后制作四角色、五敌军与 M2-M5。
7. 制作 M6、章节结局、三档平衡和整章试玩。
8. 完成可访问性、长时运行、发布包和许可证。
