# M1 3D 微缩场景试作设计

> 状态：待用户审阅
> 日期：2026-08-05
> 范围：独立试作，不替换当前 2D 主线

## 目标

验证 Tactical Grid 的第一章能否从二维地图表现迁移为固定斜俯视的 3D 科幻微缩场景，同时保持现有方格战术规则的可读性。

试作必须让玩家直接看到：

1. 单位沿移动方向真实转身。
2. 攻击时身体与武器朝目标瞄准。
3. 突击、侦察、重装、狙击和敌军拥有明显不同的轮廓。
4. 地面、墙体、门、终端和单位在 3D 视角中仍能一眼辨认。

## 范围

新增一个独立的 M1 房间试作场景，不改动 `boot.tscn`、当前 2D 战斗场景、存档格式或发布流程。

试作包含：

- 一个 12x10 的工业房间，由模块化地板、矮墙、掩体、门和终端组成。
- 固定约 55 度斜俯视的正交 3D 相机。
- 一名可操作突击角色。
- 一名哨兵和一架观察无人机。
- 左键选择、点击地面移动、点击敌人攻击、点击终端交互。
- 移动、攻击、扫描和受击的程序化 3D 表现。
- 蓝色移动范围、红色攻击范围、黄色交互提示和敌人预警。

## 视觉方向

采用低多边形硬表面科幻微缩模型：

- 单位由身体、头盔、背包、武器、肩甲和发光饰条组合。
- 突击为宽肩、青色灯带、短距脉冲器。
- 哨兵为圆形红色底盘；无人机为橙色菱形悬浮体。
- 地图使用深色工业材质、青色导光线和可交互设施光效。
- 动画由旋转、位移、后坐、缩放、阴影和粒子实现；本试作不依赖 AI 逐帧动画或骨骼高模。

## 技术边界

保留并适配现有的网格坐标、寻路、可见性、目标选择和行动预览逻辑。新增 3D 表现层负责把格子映射为三维位置，并将当前单位朝向更新为移动或攻击方向。

试作不包含：

- 迁移整张 M1 或 M2-M6。
- 修改正式战斗规则、章节剧情、技能系统或存档。
- 复杂骨骼动画、写实角色模型、语音或新发布包。
- 多角色同时出战和角色切换。

## 验收标准

1. 可从独立入口启动，不影响现有游戏启动流程。
2. 突击移动到八个方向时，模型面向与移动方向一致。
3. 点击敌人时，武器朝向目标并显示确定伤害预览。
4. 角色、哨兵、无人机、门和终端在 1280x720 下可一眼区分。
5. 同一镜头中能看清可走区域、掩体和阻挡物。
6. 操作不需要移动、攻击或结束回合按钮。
7. 现有 2D 战斗场景和自动化回归不因试作失效。
8. 完成一次人工视觉检查后，由项目负责人决定是否推进整章 3D 迁移。

## 推进决策

只有试作同时满足可读性、操作、单位辨识和性能观察四项，才进入“3D 主线迁移”计划。任一关键项不达标时，保留现有 2D 主线并调整试作，而不进行全量替换。
