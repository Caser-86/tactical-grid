## 2. 产品定义

### 2.1 一句话定位

玩家带领一支逐步组建的行动小队，探索失联工业设施，观察敌方下一步计划，利用角色能力、站位和环境设施破坏计划，营救队员并最终摧毁数据哨兵。

### 2.2 类型与平台

- 类型：章节式轻量战术冒险。
- 视角：2D 正交俯视。
- 战斗：确定性回合制，同一地图内完成探索与战斗。
- 平台：第一阶段以可独立运行的 Windows 发布包为正式交付目标。
- 首发语言：简体中文；所有玩家可见文本继续数据化，为后续本地化保留条件。
- 玩家模式：单人游戏，不包含多人和在线依赖。

### 2.3 核心承诺

每个有效玩家回合至少回答一个清楚的问题：

- 哪个敌方计划最危险？
- 应该消灭、打断、推动、保护还是绕过？
- 应该继续探索，还是先处理已经发现的风险？
- 应该使用角色能力，还是利用场景设施改变局面？

玩家不应把主要精力花在寻找按钮、猜测操作模式、重复跑图或读取长说明上。

### 2.4 正式完成后的内容规模

| 内容 | 第一章目标 |
|---|---:|
| 主线任务 | 6 |
| 可选战术行动 | 4 |
| 可部署角色 | 4 |
| 通用敌人 | 5 类 |
| 任务级特殊敌人 | 1 类猎手 |
| 章节 Boss | 1 个，两阶段 |
| 手工战术遭遇 | 28 个 |
| 环境主题 | 4 套 |
| 角色模块 | 8 个 |
| 主线首次流程 | 约 2.5 至 3 小时，包含基地、简报和剧情 |
| 主线加可选内容 | 约 3.5 至 4.5 小时 |
| 全收集和挑战重玩 | 约 5 至 7 小时 |

第一章必须包含完整开端、角色集结、冲突升级、Boss 和阶段性结局。不能以“等待后续章节”代替本章结局。

## 3. 设计原则

### 3.1 少量操作，多种结果

正式前台只保留四类行动：

1. 移动。
2. 普通攻击。
3. 每名角色一个主动能力。
4. 场景设施操作。

不增加弹药、背包整理、武器耐久、复杂 AP、技能树、姿态切换、命中百分比或独立潜行模式。

### 3.2 信息透明

在提交行动前，玩家必须知道：

- 目标格是否可达以及真实路径。
- 普通攻击是否可用以及精确伤害。
- 目标行动后的剩余生命。
- 已观察敌人的下一步意图和目标。
- 移动是否进入已知危险或触发已知反应。
- 设施操作会改变什么、持续多久、是否提高警戒。

### 3.3 深度来自组合，不来自规则膨胀

战术深度只从以下七类变量组合产生：

- 敌方公开意图。
- 角色站位与占位。
- 射程、射线和视线。
- 推动、阻挡和打断。
- 掩体与临时护盾。
- 战争迷雾和已知信息。
- 环境装置和路线变化。

任何新系统必须复用至少两个既有变量，否则不进入第一章。

### 3.4 每关只教授一个主要新规则

M1 完成全部基础操作教学。M2 至 M6 每关只引入一个主要新规则，其余内容通过已学敌人、角色和环境的重新组合产生。

### 3.5 不用消耗战填充时长

禁止通过以下方式补足时长：

- 增加敌人生命但不改变行为。
- 降低玩家伤害。
- 重复增援同一种敌人。
- 扩大空白走廊。
- 强制玩家往返同一地点。
- 添加只需点击一次、却被包装成独立阶段的设施。

## 4. 核心循环

### 4.1 单回合循环

1. 玩家查看地图变化、敌方意图和当前目标。
2. 选择一名仍可行动的队员。
3. 移动一次和行动一次，顺序自由。
4. 行动立即更新伤害、意图、迷雾、占位和任务状态。
5. 所有队员完成后进入敌方阶段。
6. 敌人按公开计划依次行动；计划失效时只执行不更致命的安全后备行为。

### 4.2 单任务循环

1. 基地查看一句任务目标、已知敌人和编队限制。
2. 进入固定手工地图并探索迷雾。
3. 完成三个至四个战术遭遇。
4. 选择是否完成一个短可选目标。
5. 达成主目标并撤离或完成 Boss 结算。
6. 返回基地，解锁角色、模块、记录或下一任务。

### 4.3 战术遭遇定义

一个正式战术遭遇必须同时包含：

- 一个一句话可说明的局部目标。
- 一组具有关系的敌人，而不是互不相关的血条。
- 至少一个可利用的地形、路线或设施条件。
- 一个新信息或局面变化时刻。
- 至少两种明显可行解法。
- 一个明确结束条件，不要求清空整张地图。

教学遭遇可以有推荐解，但普通遭遇不得只有唯一正确步骤。

## 5. 操作与镜头

### 5.1 地图直接操作

- 左键友军：选择角色并显示当前可用信息。
- 左键可达地面：沿预览路径立即移动。
- 左键可攻击敌人：立即提交普通攻击。
- 左键设施：在设施附近显示最多两个自然语言操作。
- 悬停地面：显示真实路径、终点和已知风险。
- 悬停敌人：显示伤害、剩余生命、掩体结果和意图变化。
- 右键短按：取消当前预览或关闭现场菜单。
- `Space`：结束玩家回合。
- `Tab`：选择下一名仍可行动队员。
- `F` 或双击队员：镜头回到该队员。

### 5.2 镜头控制

为避免单一操作习惯造成阻塞，同时支持：

- 左键拖动无单位、无设施的空地平移地图。
- 右键拖动平移地图；短按右键仍为取消。
- 中键拖动平移地图。
- `WASD` 平移地图。
- 滚轮缩放。
- 镜头查看设施后始终显示“返回队员”，再次点击设施、按 `Esc` 或按 `F` 均可退出查看。
- 敌方行动结束、角色受击或新目标出现时，镜头只短暂聚焦，不锁死玩家控制。

### 5.3 信息显示

- 默认状态不铺满全部红色攻击格。
- 选中友军后以柔和青色显示可移动区域。
- 真正可攻击敌人使用红色轮廓、武器连线和意图图标，不依赖整片红格。
- 路径只指向合法终点，并逐格显示经过位置。
- 敌人和友军活体占用格既不能作为路径终点，也不能作为中间格。
- UI 始终显示当前状态：选择、移动预览、攻击预览、能力、设施、敌方行动或暂停。
- 不向玩家显示旧 AP 数字，只显示“移动可用/已用”和“行动可用/已用”。

### 5.4 教学

- M1 前三个玩家回合构成安全教学。
- 一次只显示一句与当前场景对象相连的提示。
- 玩家完成对应动作后提示立即消失。
- 不使用遮挡战场的大型中央教学框。
- 教学提示可以跳过；操作帮助始终可以从暂停菜单重新查看。
- 教学结束前，脚本敌人不能通过未解释规则使玩家失能。

## 6. 角色系统

每名角色只有普通攻击、一个主动能力、一个被动和一个模块槽。模块在基地免费更换，不使用货币和技能树。

### 6.1 突击兵

- 身份：短程爆发、突破和推动。
- 普攻：短射程、高伤害。
- 主动“冲击推进”：直线推进并推开终点相邻敌人。
- 被动“贴身装甲”：靠近已观察敌人时获得一次临时防护。
- 模块 A“加压推进”：推动距离增加一格。
- 模块 B“动能回收”：成功推动敌人后获得 1 点临时护盾。

### 6.2 侦察兵

- 身份：揭开迷雾、标记和降低信息风险。
- 普攻：中短射程、较低伤害。
- 主动“区域扫描”：揭示区域并标记其中敌人。
- 被动“先行观察”：首次发现敌人时立即公开其意图。
- 模块 A“深度扫描”：扫描半径增加一格。
- 模块 B“静默识别”：扫描首次标记敌人时不提高警戒。

### 6.3 狙击手

- 身份：远程处决和取消高威胁意图。
- 普攻：长射程，高伤害，存在最小射程。
- 主动“截断射击”：造成固定伤害并取消目标当前攻击意图。
- 被动“稳定射位”：本回合未移动时普通攻击增伤。
- 模块 A“快速校准”：移动后首次普通攻击不失去全部稳定收益。
- 模块 B“连锁截断”：取消攻击意图时同时公开附近一名敌人的意图。

### 6.4 重装兵

- 身份：保护、占位和吸收已预告伤害。
- 普攻：中射程、稳定伤害。
- 主动“屏障投射”：自己和相邻友军获得固定护盾。
- 被动“重型框架”：每回合受到的第一次直接伤害减少 1。
- 模块 A“扩展屏障”：屏障覆盖距离增加一格，但自己获得的护盾减少 1。
- 模块 B“反冲装甲”：护盾完全吸收一次攻击时推动近战攻击者一格。

### 6.5 编队递进

- M1：突击兵单人开场，关内救出侦察兵。
- M2：突击兵和侦察兵，关内救出狙击手。
- M3：从三人中选两人，关内救出重装兵。
- M4 至 M6：从四人中选择三人。
- 关卡不能因未选择某个职业而软锁；不同编队只改变解法和风险。

## 7. 敌人体系

### 7.1 通用行为要求

- 每类敌人拥有独立计划策略，不能主要依靠共同的“向最近玩家靠近”。
- 已观察敌人在玩家回合开始时公开一个可执行意图。
- 新敌人首次出现的当前回合不能立即造成致命伤害。
- 敌人失能后立即停止输入、AI、碰撞、占位和意图，并在反馈完成后淡出。
- 同时活跃敌人上限：M1 至 M3 为 3，M4 至 M6 为 4。

### 7.2 巡逻哨兵

- 问题：直接火力和路线封锁。
- 行为：在守位、寻找射线和攻击之间选择；不会无条件追到玩家身边。
- 意图：直线攻击箭头或短移动路径。
- 视觉：直立轮廓、长枪、红色大肩甲。

### 7.3 侦察无人机

- 问题：信息暴露和警戒升级。
- 行为：巡查盲区、扇形扫描、标记角色；基础直接伤害很低。
- 意图：明确扇形扫描区和警戒后果。
- 视觉：横向宽翼、白紫扫描灯、悬浮阴影。

### 7.4 狙击哨兵

- 问题：必须在下一敌方阶段前处理的高威胁射线。
- 行为：选择远距离射位，瞄准一整回合后开火；射线被阻断时转为警戒或重新定位。
- 意图：贯穿地图的窄射线、目标头像和精确伤害。
- 视觉：细长结构、超长枪管、冰白镜头和红色瞄准灯。

### 7.5 盾卫

- 问题：敌人之间的保护关系。
- 行为：优先移动到高价值敌人身边并提供减伤；落单时守住狭窄路线。
- 意图：盾牌连线和被保护目标，不使用普通攻击箭头冒充保护。
- 视觉：最宽轮廓、六边形盾牌、橙色大面积装甲。

### 7.6 协议工程师

- 问题：改变地图和设施状态。
- 行为：优先操作门、摄像头、增援信标或危险设施；暴露且无可用设施时撤向安全区。
- 意图：设施图标、操作路径和结果预览。
- 视觉：非对称工具背包、黄色机械臂、青色线缆。

### 7.7 猎手

- 问题：惩罚队伍分散，但不使用瞬移或隐藏伤害。
- 行为：锁定最远或落单角色，公开追踪路线；目标与队友会合后转为封锁。
- 使用范围：M5 和可选行动 O4，不作为普通关卡重复敌人。
- 视觉：低姿态、双刃前臂、白色面罩和高亮追踪脉冲。

### 7.8 数据哨兵 Boss

- 第一阶段：通过两个公开终端关闭护盾，同时处理 Boss 的范围意图和少量支援。
- 第二阶段：Boss 失去护盾，循环使用三种完全预告的区域攻击。
- 阶段变化来自攻击方式、地图安全区和终端状态，不依靠单纯增加生命。

## 8. 视觉辨识标准

角色和敌人的区分必须同时依靠：

1. 整体轮廓。
2. 大面积专属装饰色。
3. 武器或设备长度与方向。
4. 独立意图形状和音效。

脚下队伍圆环、头顶文字和小徽章只能辅助，不能承担主要辨识职责。

正式辨识门：

- 在默认 1080p、100% UI 缩放和实际战场缩放下测试。
- 在 75% 地图缩放下仍能区分 M1 三类敌人。
- 灰阶模式下仍可通过轮廓和设备区分。
- 敌我双方不能只通过蓝色或红色区分。
- 四方向素材必须是独立方向构图，不能只旋转同一张图。

## 9. 主线任务结构

第一章主线共 20 个手工战术遭遇。每关拥有一个主目标、一个短可选目标和一个明确高潮。

### 9.1 M1 回声失联

- 编队：突击兵，关内救出侦察兵。
- 主目标：找到失联侦察兵并共同撤离。
- 可选目标：取得事故记录，补充档案并完成本关战术挑战。
- 主要敌人：哨兵、无人机、盾卫。
- 教授：选择、移动、攻击、意图、迷雾、摄像头和撤离。
- 遭遇数：3。
- 首次目标时长：12 至 18 分钟。

遭遇结构：

1. 南侧货运坪：三回合安全教学，一名哨兵建立移动、攻击和意图规则。
2. 分岔与营救：维修摄像头路线提供信息，货柜路线更短但遇到无人机；路线直接存在于地图，不弹出选择菜单。
3. 共同撤离：营救侦察兵后出现盾卫保护组合，要求第一次使用扫描或推动改变局面。

吊机和摄像头是战术工具，不是必须依次点击的流程门。事故记录位于短支路，往返不超过两个玩家回合。

### 9.2 M2 熄灯协议

- 编队：突击兵、侦察兵，关内救出狙击手。
- 主目标：关闭区域封锁并救出狙击手。
- 可选目标：关闭冷却控制室，补充设施档案并完成本关战术挑战。
- 主要敌人：哨兵、无人机、狙击哨兵。
- 新规则：狙击射线和电力状态。
- 遭遇数：3。
- 首次目标时长：18 至 22 分钟。

遭遇结构：

1. 首次狙击射线：玩家有一个完整回合处理已预告射线。
2. 断电或旁路：两条空间路线都解除封锁，但分别改变视野和敌人位置。
3. 营救与反制：狙击手加入并立即用截断射击解决一个公开高威胁意图。

### 9.3 M3 断轨营救

- 编队：三选二，关内救出重装兵。
- 主目标：改变磁轨并带重装兵离开。
- 可选目标：恢复维修舱，补充中转站档案并完成本关战术挑战。
- 主要敌人：哨兵、无人机、狙击哨兵、盾卫。
- 新规则：盾卫保护关系和轨道危险区。
- 遭遇数：3。
- 首次目标时长：20 至 25 分钟。

遭遇结构：

1. 盾卫护送：分离盾卫与哨兵，教学保护关系。
2. 轨道切换：改变轨道同时改变掩体和安全区域。
3. 重装撤离：救出重装兵后用屏障抵挡一组已预告攻击。

### 9.4 M4 囚笼密钥

- 编队：四选三。
- 主目标：取得进入零号终端的核心密钥。
- 可选目标：释放技术员，补充监区档案并完成本关战术挑战。
- 主要敌人：五类通用敌人。
- 新规则：协议工程师改变设施。
- 遭遇数：4。
- 首次目标时长：25 至 30 分钟。

遭遇结构：

1. 工程师与摄像头：工程师试图恢复扫描网络。
2. 牢门控制：玩家选择先取密钥还是先救技术员。
3. 双区域反应：已放弃的区域会产生一种可预告后果，而不是无提示增援。
4. 持钥撤离：敌人尝试重新锁门，玩家可击倒、打断或绕行。

### 9.5 M5 反向猎杀

- 编队：四选三。
- 主目标：摧毁追踪阵列。
- 可选目标：关闭增援信标并取得追踪档案。
- 主要敌人：工程师、盾卫、狙击哨兵和猎手。
- 新规则：猎手公开追踪。
- 遭遇数：4。
- 首次目标时长：25 至 30 分钟。

遭遇结构：

1. 首次锁定：猎手标记落单角色，玩家学习集合可改变其计划。
2. 追踪阵列：工程师试图切换追踪目标。
3. 信标支线：关闭信标减少最终拦截，但不是主线必需。
4. 反向围捕：玩家利用设施和队伍站位迫使猎手进入不利位置。

### 9.6 M6 零号终端

- 编队：四选三。
- 主目标：摧毁数据哨兵。
- 可选目标：保留核心档案，改变结局文本和收藏记录。
- 主要敌人：数据哨兵和少量分批支援。
- 新规则：两阶段 Boss；不再教授新的基础输入。
- 遭遇数：3，包括一个两阶段 Boss 遭遇。
- 首次目标时长：30 至 40 分钟。

遭遇结构：

1. 外围终端：复习工程师、护盾和射线组合。
2. 护盾阶段：操作两个公开终端，同时改变 Boss 范围攻击。
3. 核心阶段：三种循环危险区，要求综合使用位移、扫描、打断和保护。

Boss 击败后必须有短结局、队员状态总结、章节奖励和返回主菜单/继续基地的正常流程。

## 10. 可选战术行动

四个可选行动共 8 个手工遭遇，每个行动 10 至 18 分钟。它们复用既有规则和环境套件，但使用独立锁定布局，不复制主线地图。

### 10.1 O1 静默取证

- 解锁：完成 M1。
- 编队：突击兵、侦察兵。
- 重点：无人机扫描和低警戒路线。
- 遭遇：避开或关闭扫描网；取证后从另一条路线撤离。
- 奖励：侦察兵模块 B。

### 10.2 O2 过载隔离

- 解锁：完成 M2。
- 编队：三选二。
- 重点：电力、门和提前预告危险区。
- 遭遇：进入过载区；在设施循环中关闭核心。
- 奖励：突击兵模块 B。

### 10.3 O3 囚徒转移

- 解锁：完成 M3。
- 编队：四选三。
- 重点：盾卫、牢门和非战斗保护目标。
- 遭遇：打开囚室；保护技术员穿过短撤离线。
- 奖励：重装兵模块 B。

### 10.4 O4 盲区追踪

- 解锁：完成 M5。
- 编队：四选三。
- 重点：猎手追踪与队伍集合。
- 遭遇：主动制造落单诱饵；在预设包围区击败或困住猎手。
- 奖励：狙击手模块 B 和追踪档案。

## 11. 成长、基地与重复游玩

### 11.1 成长

- 营救角色永久加入后续任务编队。
- 角色加入时解锁模块 A。
- 完成对应可选行动解锁模块 B。
- 每名角色只有一个模块槽，基地免费更换。
- 不使用经验等级、随机装备、货币商店和属性点分配。

### 11.2 基地

基地只承担：

- 选择下一任务或可选行动。
- 查看一句主目标、已知敌人和可选奖励。
- 选择合法编队。
- 更换角色模块。
- 查看角色档案、事故记录和章节进度。
- 保存、设置和退出。

基地不能成为复杂经营游戏，也不能要求玩家在每关前重复整理大量装备。

### 11.3 重玩价值

每个主线任务记录三项挑战，但挑战不阻断主线和角色解锁：

- 完成主目标。
- 完成可选目标。
- 达成该关专属战术条件，例如无人失能、警戒不超过搜索或未让工程师完成设施操作。

不同编队、路线、模块和可选目标构成重玩变化；不使用随机命中制造差异。

## 12. 地图与内容生产标准

### 12.1 地图结构

每张主线地图必须包含：

- 三至四个主要战术区域。
- 两条能从地图空间直接辨认的主路线。
- 一个短可选空间或目标。
- 一个初见时可识别的主地标。
- 开场、中段和最终阶段检查点。
- 已清理区域快速集合规则。

主要区域之间正常移动不超过两个完整玩家回合。任何路线连续三回合没有新信息、威胁、交互或目标变化时必须缩短或补充有效内容。

### 12.2 遭遇内容表

每个遭遇在进入制作前必须登记：

- 遭遇 ID、目标和结束条件。
- 参与敌人及其关系。
- 玩家可利用的地形或设施。
- 至少两种预期解法。
- 新信息出现时机。
- 失败压力和安全后备规则。
- 检查点恢复状态。
- 所需美术、VFX、音效和测试。

缺少上述字段的敌人摆放不得作为正式内容进入锁定地图。

## 13. 美术生产计划

### 13.1 风格

- 保留 V1/V2 现有 2D 正交俯视科幻工业风格。
- 不使用已经放弃的 3D 或斜俯视小样。
- 现有合法地板、边界、货柜、吊机、冷却、轨道和核心设施资源优先复用。
- 新单位采用清晰轮廓、大面积装饰色和一致光向，不追求缩小后不可见的细节。

### 13.2 单位预算

- 四名玩家角色乘四方向：16 张正式运行时图。
- 五类普通敌人乘四方向：20 张。
- 猎手乘四方向：4 张。
- Boss 两阶段乘四方向：8 张。
- 主要角色与指挥官肖像：6 至 8 张。
- 单位图使用透明背景，按实际运行时尺寸导入和测试。

### 13.3 小样门

正式批量生产前只制作：

- 突击兵。
- 侦察兵。
- 哨兵。
- 无人机。
- 盾卫。

五个单位必须在 M1 实际场景、默认缩放、75% 缩放、灰阶和色觉辅助模式中通过辨识，再批量生成剩余方向和角色。原图尺寸、透明通道和文件存在不能单独构成通过。

### 13.4 动画与 VFX

第一章不制作完整逐帧骨骼动画。四方向静态单位结合 Godot 程序化表现：

- 移动插值和朝向切换。
- 待机轻微呼吸或悬浮。
- 攻击起手、后坐和枪口/能力轨迹。
- 受击闪光、位移和伤害数字。
- 护盾吸收、扫描、推动、截断和设施结果。
- 失能动画、淡出和占位释放。
- Boss 护盾破裂与核心受击。

## 14. 音频计划

最低正式音频范围：

- 基地、普通潜入、警戒和 Boss 音乐各一首。
- Echo Yard、Cooling Works、Transit Hub、Sentinel Core 环境氛围各一组。
- 四名角色的移动、普通攻击和主动能力差异音。
- 五类敌人、猎手和 Boss 的识别、意图和行动差异音。
- UI 选择、取消、目标更新、设施成功、警戒提升、伤害、护盾、失能、胜利和失败音效。

音效必须与视觉反馈同步；关闭音乐后，玩家仍能通过音效区分敌方高威胁意图。

所有外部资源必须记录来源、作者、链接、许可证、是否修改和使用位置。来源不明资源不得进入发布包。

## 15. 技术边界

### 15.1 保留

- 当前 V2 数据仓库、锁定地图、稳定实体 ID 和独立存档。
- 确定性攻击与精确预览。
- 一次移动加一次行动。
- 三态战争迷雾、公开意图、检查点和任务结果。
- V1/V2 独立入口、用户目录、测试和发布验证。

### 15.2 定向重构

不推倒重写，但在实施相关功能时逐步拆分：

- V2 输入协调器：只负责选择、移动、攻击、设施、取消和输入锁。
- V2 镜头控制器：只负责平移、缩放、聚焦和设施查看返回。
- V2 表现协调器：只负责范围、路径、意图、伤害和反馈。
- V2 任务导演：只负责目标、遭遇、检查点和任务事件。
- 敌人策略：每类敌人拥有独立计划器，共享合法性校验和安全后备行为。

共享 V1 的大控制器只保留稳定基础接口。V2 新规则不得继续无边界堆入共享控制器。

### 15.3 数据合同

角色、敌人、任务、遭遇、设施、模块和资源目录继续由数据定义。运行时拒绝：

- 重复或缺失稳定 ID。
- 不可达主目标和撤离点。
- 超过活跃敌人上限。
- 无合法后备行为的敌方意图。
- 缺少正式资源的可部署单位。
- 检查点无法恢复的任务阶段。

## 16. 测试策略

### 16.1 自动合同测试

必须覆盖：

- 移动、行动及两种合法顺序。
- 真实路径、占位、绕路和击倒后释放。
- 确定性攻击、伤害预览和死亡清理。
- 五类普通敌人、猎手和 Boss 意图。
- 敌人计划失效后的安全后备行为。
- 迷雾移动后同事务刷新。
- 设施结果和警戒变化预览。
- 任务阶段、可选目标、检查点和恢复。
- 角色、模块、任务和结局存档。
- V1/V2 发布、存档和入口隔离。

### 16.2 脚本流程测试

为每个主线和可选行动建立公开接口流程测试：

- 只能使用正式选择、移动、攻击、能力、设施和结束回合接口。
- 不直接写角色位置。
- 不把敌人伤害改为零。
- 不直接触发任务完成事件。
- 覆盖每条主路线、可选目标、失败重试和检查点恢复。

脚本流程证明流程可达，不证明趣味性。

### 16.3 视觉与音频矩阵

每个任务至少捕获：

- 开场。
- 一般探索。
- 普通战斗。
- 高威胁意图。
- 可选目标。
- 中段变化。
- 最终阶段。
- 胜利和失败结算。

矩阵覆盖 1280x720、1920x1080、默认、灰阶、红绿色觉辅助和 UI 文字缩放。音频测试覆盖总线、设置持久化、关键反馈存在和无头测试安全行为。

## 17. 单人真人测试协议

### 17.1 约束说明

项目负责人是唯一真人测试者。该模式可以验证完整性、稳定性、操作感、节奏和项目负责人认可的趣味性，但不能充分证明陌生玩家首次可理解性。此风险必须保留在发布报告中，不能用自动测试宣称已经消除。

### 17.2 测试环境

- 只使用重新导出的独立 Windows 包。
- 不打开 Godot 编辑器。
- 使用 V2 独立新存档或指定检查点。
- 关闭开发标记、调试传送和外部操作说明。
- 开启本地匿名会话日志；日志不得包含私人内容。

### 17.3 三种测试

#### 局部操作测试

- 目标：验证一项新交互、敌人或反馈。
- 时长：单次 5 至 15 分钟。
- 记录：无效点击、取消、误操作、镜头丢失和不知道下一步的位置。

#### 整关测试

- 目标：从任务简报开始，不使用调试功能完成整关。
- 记录：时长、回合、路线、遭遇、伤害、失能、设施、能力、可选目标和重试。
- 每关正式锁定前至少完成故事和标准难度各一次。

#### 第一章发布测试

- 目标：从新存档开始连续完成基地、六主线、至少两个可选行动、失败重试、保存恢复、Boss 和结局。
- 允许分多次启动，但必须通过正式存档继续。
- 完成后验证返回基地、主菜单、设置和退出。

### 17.4 自动记录字段

- 任务、版本、难度和存档身份。
- 开始、完成或失败时间。
- 玩家和敌方回合数。
- 每名角色移动、攻击、能力和设施次数。
- 无效点击、取消和重复点击次数。
- 镜头返回队员和手动平移次数。
- 受到、造成和避免的伤害。
- 敌方意图被击杀、推动、打断、保护或绕过的次数。
- 不活动超过十秒的位置和当前目标。
- 失能、检查点重试、软锁和崩溃。

### 17.5 单人验收门

- 不看外部说明可以完成六个主线任务。
- M1 开始 60 秒内自然完成第一次移动。
- M1 开始 90 秒内自然完成第一次攻击。
- 任意时刻可以用一句话说明当前目标和结束条件。
- 不需要猜测鼠标当前处于移动、攻击还是设施模式。
- 在实际缩放下能区分当前关卡全部敌人类型。
- 每关至少出现三次需要在两种有效方案间权衡的决定。
- 不出现连续三回合只有赶路或重复攻击。
- 普通敌方回合不超过八秒。
- M1 首次目标 12 至 18 分钟，完整主线约 2.5 至 3 小时。
- 没有单位重合、穿越活体、尸体占位、错误路径、迷雾延迟、镜头锁死或任务软锁。
- 失败原因、检查点状态和下一次可改进方式清楚可见。

## 18. 发布标准

第一章只有在以下条件全部满足时，才可标记为正式可发布：

- 六个主线任务和四个可选行动均为正式内容。
- 四名角色、五类普通敌人、猎手和 Boss 具备正式可辨识美术。
- 所有主线、可选目标、失败、重试、胜利和结局流程闭环。
- 基地、编队、模块、设置、存档和退出可用。
- 无占位单位、默认图标、临时文字、测试入口或调试开关进入发布包。
- 音乐、环境音、战斗、UI 和关键提示音完整。
- 自动合同、脚本流程、视觉、音频、性能、长时和存档恢复测试通过。
- 单人真人发布测试通过并保留原始记录。
- Windows 包在干净 V2 用户目录中可启动、保存、继续、通关和正常退出。
- 外部资源来源和许可证完整且允许当前发布方式。
- V1 的代码、存档、文档入口和发布结果未被覆盖。

自动断言数量不是完成标准本身。最终标准仍是项目负责人可以不打开 Godot 编辑器，直接启动发布包，理解、完整游玩并正常结束第一章。

## 19. 实施阶段与出口门

### 阶段 0：规格统一和基线冻结

- 标记被替代的旧 M1/M2 扩充目标。
- 更新总规格、路线图和任务索引的权威引用。
- 保存当前 V2 可运行基线和发布包。
- 出口门：所有后续任务只引用一套产品目标。

### 阶段 1：M1 核心乐趣切片

- 完成直接地图操作、镜头控制和非阻断教学。
- 完成哨兵、无人机、盾卫的独立行为与辨识小样。
- 重排 M1 三个遭遇，不先制作后续关卡。
- 出口门：项目负责人可以顺畅完成 M1，并确认核心回合具有明确决策。

### 阶段 2：M1 正式完成

- 接入 M1 正式地图构图、单位、VFX、音效、可选记录、检查点和结算。
- 完成故事/标准难度整关测试和发布包测试。
- 出口门：M1 通过本文单人验收门。

### 阶段 3：共享内容管线与 M2-M3

- 固化遭遇数据合同、独立敌人策略和模块系统。
- 完成 M2、M3 及 O1、O2。
- 出口门：三名角色和四类敌人形成多种有效组合，检查点和存档稳定。

### 阶段 4：完整小队与 M4-M5

- 完成 M4、M5 及 O3、O4。
- 接入协议工程师、猎手、四人编队选择和完整模块。
- 出口门：不同三人编队都能合法通关且不存在唯一必选角色。

### 阶段 5：M6 与章节闭环

## 21. 主要风险与控制

### 21.1 唯一真人测试者熟悉项目

- 风险：无法可靠代表陌生玩家首次体验。
- 控制：使用干净发布包、隐藏开发信息、记录无效操作和停顿；发布报告明确保留该风险。

### 21.2 AI 美术方向一致性

- 风险：四方向角色不一致，缩小后区别消失。
- 控制：先做五单位小样；按实际场景和灰阶验收后再批量生产。

### 21.3 内容量扩大导致系统分叉

- 风险：每关添加专用硬编码，维护和测试成本失控。
- 控制：先建立遭遇、设施、任务和敌人策略合同；每种新规则必须至少复用两次。

### 21.4 自动测试掩盖趣味问题

- 风险：流程可达被误报为正式可玩。
- 控制：自动测试、脚本通关和真人趣味结论分栏报告，任何一项不得替代另一项。

### 21.5 用内容数量代替内容质量

- 风险：敌人和地图增加，但每回合仍只有重复攻击。
- 控制：每个遭遇登记敌人关系、环境条件、两种解法和变化时刻；不符合模板不得锁定。
