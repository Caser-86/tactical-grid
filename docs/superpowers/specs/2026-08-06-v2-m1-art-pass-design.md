# V2 M1 美术整合设计

## 目标

将 V2 第一章 M1 从“系统可玩的灰盒”提升为“视觉信息完整、角色可辨识、地图有场景层次”的可试玩版本，同时保持 V1 完全不变。

## 当前问题

- M1 运行时已经有地面、障碍物、单位、目标点和特效资源，但许多对象仍以 64/96 像素通用图显示，角色轮廓和阵营差异不足。
- 地图构图偏向左下，屏幕上方和右侧存在过大的空黑区域，削弱了关卡规模感。
- 关键设施和目标点虽可交互，但视觉优先级不足，玩家不容易把它们理解为摄像头、营救点和撤离点。
- 现有资源清单已经区分 V2 目录，但需要补齐“实际接入位置、尺寸、用途和许可证”记录。

## 设计方向

采用“复用现有资源为主，少量新增资源补关键缺口”的垂直切片方案：

1. 保持现有赛博工业、蓝橙高对比和俯视战棋风格。
2. 先修正运行时的画面构图和层级，再扩大资源数量；单纯增加图片不能解决黑边和信息层级问题。
3. 玩家角色使用蓝色/青色装备轮廓，敌方单位使用红色/紫色机械轮廓，并使用顶部标记和底座颜色作为第二重识别。
4. M1 只强化四类可见对象：玩家与敌人、地面与掩体、交互设施、攻击/营救/撤离反馈。
5. 不制作与当前 M1 无关的 Boss、基地或第二章资源。

## 第一批资源范围

- 角色：突击兵、侦察兵、基础哨兵、攻击无人机各一套正式运行图；优先复用已有 V2 runtime 图，并补充颜色装饰或可读的轮廓层。
- 设施：东侧摄像头、侦察兵营救点、右上撤离点各一套高对比运行图。
- 场景：Echo Yard 地面变体、货物堆/掩体、警示灯、边界和一个主地标，用来打破大面积重复地砖。
- 反馈：移动路径、攻击弹道、命中、营救成功和撤离确认继续复用现有特效，并补充必要的颜色和缩放规则。

## 隔离规则

- 所有新文件只能放在 `tactical-grid/client/assets/generated/chapter1/runtime` 或 V2 专用文档目录。
- V2 代码不得读取 V1 worktree、V1 专用存档或 V1 资源路径。
- 不修改 V1 的场景、数据、ArtCatalog 路径和发布门禁。
- 资源来源必须在 `tactical-grid/client/data/v2/resource_manifest.md` 或 `tactical-grid/client/assets/v2/README.md` 记录。

## 验收标准

- 1920x1080 和 1280x720 下，地图主体居中且不被 HUD 遮挡，初始视图不再出现大面积无意义黑边。
- M1 开场截图中，玩家、敌人、摄像头、营救点和撤离点可以仅凭颜色与轮廓区分。
- 选中、移动、攻击预览、营救和撤离截图均能看到对应的视觉反馈。
- 资源清单含文件路径、尺寸、用途、生成/授权来源和许可证结论。
- V2 针对性测试、视觉矩阵和完整发布门禁全部通过；V1 测试结果不发生变化。
