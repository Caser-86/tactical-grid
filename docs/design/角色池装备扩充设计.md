### 1.5 招募新兵系统

```
基地 → 兵营 → 招募
  - 每隔 3 关卡可招募 1 名新兵
  - 新兵属性随机生成（种子可复现）
  - 新兵职业玩家自选
  - 新兵初始等级 = 当前章节等级
  - 新兵有随机背景故事（AI 生成）
  - 新兵有随机外观（AI 生成立绘）
  - 招募消耗：信用点 500-2000（按等级）
```

**新兵生成表**：
```json
{
  "recruit_generation": {
    "name_pool": ["AI生成 200 个名字"],
    "stat_variance": {
      "base": [3, 8],
      "bonus_points": 5,

    },
    "personality_traits": [
      "冷静", "热血", "谨慎", "鲁莽", "沉默", "话痨",
      "老兵", "新丁", "理想主义", "实用主义"
```
