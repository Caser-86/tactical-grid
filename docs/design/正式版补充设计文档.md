enum ErrorSeverity {

### 7.2 崩溃恢复

| 场景 | 恢复策略 |
|------|---------|
| 游戏崩溃 | 加载最近自动存档（每回合保存） |
| 关卡内异常 | 回滚到本回合开始状态 |
| 网络断开 | 离线继续，重连后同步 |
| 存档损坏 | 加载上一个未损坏存档 |
| 资源加载失败 | 使用占位资源，记录日志 |
| API 请求失败 | 重试 3 次，失败后使用缓存 |

### 10.2 伤害计算公式

```
最终伤害 = 基础伤害 × (1 - 减伤百分比) - 固定减伤

减伤百分比 = 护甲减伤%（来自护甲值）
固定减伤 = 0（默认）

暴击伤害 = 最终伤害 × 暴击倍率

示例：
  基础伤害 50
  护甲 12（减伤 12%）
  最终伤害 = 50 × (1 - 0.12) = 44
  暴击（1.5×）= 44 × 1.5 = 66
```
