## 1. 剧情叙事系统

### 1.1 世界观

**背景设定**：2087 年，全球被名为"矩阵协议"的 AI 网络接管。玩家指挥一支名为"回声"的地下抵抗组织，在废墟城市中执行战术任务，逐步瓦解矩阵协议的控制节点。

**阵营**：

| 阵营 | 立场 | 代表色 | 单位特征 |
|------|------|--------|---------|
| 回声（玩家） | 抵抗组织 | 蓝色 | 多职业搭配、灵活战术 |
| 矩阵协议军 | AI 统治者 | 红色 | 机械单位、标准化、数量多 |
| 自由佣兵 | 中立 | 黄色 | 随机出现，可敌可友 |
| 废土掠夺者 | 混乱 | 绿色 | 野蛮、陷阱多、装备差 |

**主要角色**：

| 角色 | 身份 | 定位 |
|------|------|------|
| 指挥官（玩家） | 回声指挥官 | 玩家本人 |
| 阿尔法 | 突击兵队长 | 教程引导 NPC |
| 莉拉 | 狙击手/情报官 | 剧情推进 NPC |
| 博士 | 医疗兵/科学家 | 装备研发 NPC |
| 哨兵 | 侦察兵/AI 叛逃者 | 世界观揭秘 NPC |
| 审判者 | 矩阵协议精英 | 反派 Boss |
| 架构师 | 矩阵协议核心 AI | 最终 Boss |

### 1.2 叙事结构

```
战役结构（5 章 × 4-6 关 = 22-30 关）

第一章：觉醒（教程章）
  - 引入基础规则、5 个职业
  - Boss：数据哨兵

第二章：深入敌后
  - 引入高地、可破坏掩体
  - Boss：重装审判者

第三章：背叛者
  - 引入潜行、陷阱、视野系统
  - Boss：影子佣兵（前队友）

第四章：围城
  - 引入天气、增援时钟、多阶段任务
  - Boss：矩阵将军

第五章：终局
  - 综合所有机制
  - 最终 Boss：架构师（三阶段）
```

### 1.4 分支剧情

| 关键选择点 | 影响 |
|-----------|------|
| 第一章任务方式（潜行/强攻） | 第二章敌人配置不同 |
| 第三章是否救出叛逃 AI | 影响第五章可用单位 |
| 第四章是否牺牲 NPC | 影响结局 |
| 第五章最终选择 | 3 种结局 |

**结局**：
- **A 结局**：摧毁架构师，人类独立重建（需全队存活）
- **B 结局**：与架构师融合，人机共存（需救出叛逃 AI）
- **C 结局**：失败结局，矩阵协议继续统治（关键 NPC 全灭）

## 3. 基地与间章系统

### 3.1 基地功能

关卡之间的玩家"大本营"，以 2D 场景呈现：

| 区域 | 功能 |
|------|------|
| 指挥室 | 选择下一关、查看战役进度 |
| 兵营 | 角色管理、升级、技能点分配 |
| 军械库 | 装备管理、商店、制造、拆解 |
| 医疗舱 | 治疗受伤角色（关卡中受伤需时间恢复） |
| 实验室 | 研发新装备/技能（消耗情报点） |
| 训练场 | 自定义对战、测试阵容 |
| 档案室 | 剧情回顾、角色关系、世界观 |

### 3.2 角色受伤与恢复

```yaml
injury_system:
  downed_in_mission:
    - status: "受伤"
    - recovery_time: 1-3 关卡（不能出战）
    - can_speed_up: 消耗情报点立即恢复
  critical_injury:
    - status: "重伤"
    - recovery_time: 3-5 关卡
    - permanent_debuff: 永久 -1 某属性（可选）
  death:
    - mode_classic: 永久死亡（经典模式）
    - mode_casual: 倒地后可复活（休闲模式）
```

### 3.3 研发系统

| 研发项目 | 消耗 | 效果 |
|---------|------|------|
| 新武器型号 | 情报点 + 材料 | 解锁新武器 |
| 装备改造 | 情报点 + 材料 | 装备强化上限 |
| 技能解锁 | 情报点 | 解锁新技能树节点 |
| 职业进阶 | 情报点 | 解锁双职业分支 |
| 基地设施 | 情报点 + 信用点 | 基地功能升级 |

## 4. PvP 多人对战

### 4.1 对战模式

| 模式 | 说明 | 时长 |
|------|------|------|
| 排位赛 | 1v1，同回合制，段位升降 | 15-25 分钟 |
| 休闲赛 | 1v1，无段位影响 | 15-25 分钟 |
| 锦标赛 | 周末限时，8-16 人淘汰赛 | 1-3 小时 |
| 自定义 | 好友对战，可调规则 | 自定 |

### 4.2 同步回合制（Wegrow）

为解决"等待时间长"问题，采用**同步回合制**：

```
阶段 1：双方同时布署（30 秒）
阶段 2：双方同时下达指令（60 秒/单位）
  - 双方都在规划移动和攻击
  - 看不到对方本回合指令
阶段 3：同时结算
  - 按速度排序执行
  - 同一格两人移动 → 速度高者优先
  - 互相攻击 → 同时受伤
阶段 4：结算回合效果 → 回到阶段 2
```

**优势**：双方同时操作，等待时间减半。

### 4.3 阵容规则

```yaml
pvp_rules:
  team_size: 4
  unit_level_cap: 10
  banned_items:
    - revival_needle    # 禁用复活针
    - cloak_invisibility # 禁用隐身斗篷
  point_system:
    total_point_cap: 100
    unit_cost:
      assault: 25
      sniper: 30
      heavy: 25
      medic: 20
      scout: 20
    # 玩家在 100 点内自由搭配 4 人
  map_pool:
    - pvp_arena_01  # 10×8 对称
    - pvp_arena_02  # 14×10 对称
    - pvp_arena_03  # 10×8 非对称
```

### 5.2 渐进式信息披露

```
第一次游玩只显示：
  - 移动范围（高亮）
  - 攻击范围（高亮）
  - 命中率

第 2 关后解锁显示：
  - 危险区（敌人下回合可攻击范围）
  - 掩体指示器

第 3 关后解锁显示：
  - 视线指示器
  - 高地加成提示

第 5 关后解锁显示：
  - 敌人意图预告
  - AP 消耗预览

设置中可随时开启全部显示（老玩家）
```

### 5.3 智能提示系统

| 场景 | 提示 |
|------|------|
| 单位暴露在危险区 | "该单位将被 2 个敌人攻击" |

## 7. 日常与赛季系统

```yaml
daily_quests:  # 每天 3 个，刷新
  - "完成 3 场战斗"
  - "使用突击兵击杀 5 人"
  - "零阵亡通关 1 次"
  - "使用 3 种不同职业"
  - "完成 1 场 PvP"
rewards:
  per_quest: credit_100
  all_done: intel_10
```

### 7.2 周常任务

```yaml
weekly_quests:  # 每周 5 个
  - "通关 10 场战斗"
  - "完成 1 场困难难度"
  - "PvP 胜利 5 场"
  - "收集 10 件装备"
  - "角色升 5 级"
rewards:
  per_quest: credit_500
  all_done: intel_50 + random_rare_equipment
```

### 7.3 赛季系统

```yaml
season:
  duration: 12 周
  battle_pass:
    free_tier: 50 级
      rewards: 信用点、消耗品、普通装备
    premium_tier: 50 级
      cost: 950 情报点
      rewards: 皮肤、传说装备、角色、头像框

    - "废墟围城"（第 1 赛季）
    - "深海突袭"（第 2 赛季）
    - "沙漠风暴"（第 3 赛季）
  season_mechanic:
    - 每赛季引入 1 个新地图机制（天气/日夜/毒雾等）
```
