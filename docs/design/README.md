## 成品目标

Tactical Grid 是一款离线 Windows 单机回合制战术游戏。玩家从主菜单创建或继续存档，在基地选择任务，通过五章手工战役推进到明确结局。

当前只生产第一章。第一章必须先成为新玩家无需外部说明即可完整游玩的正式切片，第二至第五章随后按同一标准制作。

## 核心体验

玩家拥有移动额度和 2AP，通过观察已侦测敌人的意图，争夺战术网络节点，并使用摄像头、门、炮塔、电力和增援信标改写战局。

核心不是格子射击本身，而是：

1. 获取可靠信息。
2. 判断最危险的已知计划。
3. 用角色能力和设施改变计划。
4. 承担警戒和路线选择的后果。

正式第一章规格见
[战术网络重设计](../superpowers/specs/2026-07-30-chapter-one-tactical-network-redesign.md)。

## 首章范围

- 六个手工制作任务和一个三阶段 Boss。
- 四名可部署角色：突击、狙击、重装、侦察。
- 五种敌军职责和事件驱动增援。
- 战争迷雾、最后已知位置、观察到的敌方意图。
- 战术网络、警戒、任务/情报/小队结算徽章。
- 基地、成长、存档、设置、暂停、失败重试和章节结局。
- 先做 M1，真人通过后再生产 M2-M6。

## 平台与技术边界

- 平台：Windows 桌面。
- 模式：离线单人。
- 正式版本为纯 Godot 离线单机，不包含服务端或在线账号系统。
- 正式关卡：客户端锁定地图和版本化模式。
- 资源：AI、程序化、自有或许可明确的开源资源。
- 版本：第一章候选版属于 0.x；五章完成并通过发布门后才进入 1.0。

## 明确非目标

- PvP、赛季、Battle Pass、公会和在线服务。
- 移动端、MOD、地图编辑器和 UGC。
- 实时潜行、时间线编排和独立黑客小游戏。
- 逐回合回退、永久死亡和复杂伤员系统。
- 程序随机主线地图、无限增援和大型随机掉落。
- 载具、动态天气和日夜循环。

## 设计原则

1. 一项机制必须有玩家可见目标、反馈、失败条件和测试，才进入正式关卡。
2. 先解决信息、输入和镜头，再扩大地图和内容量。
3. 每个新敌人改变玩家优先级，每个设施改变路线、视野、火力或增援。
4. 角色靠体型、武器、姿态、装备和颜色共同区分。
5. 美术和音频先做一个运行时小样，验收后批量制作。
6. 自动化证明规则稳定，真人试玩判断理解、节奏和趣味。
7. 任何扩大范围的提案先更新批准规格和路线图。
