# Tactical Grid 活跃设计范围

本文件定义当前首发版本的设计边界。详细任务和验收以 [接管路线图](../PROJECT_TAKEOVER_ROADMAP.md) 为准；源代码和测试结果优先于任何设计文字。

## 首发目标

制作一款可离线运行的 Windows 单机回合制战术游戏：玩家从主菜单创建或继续存档，在基地选择任务，完成战斗与结算，推进至明确结局，并可安全退出和继续游戏。

## 核心体验

- 方格地图上的 2AP 回合制战术战斗。
- 掩体、视线、移动成本、技能、物品、警戒与敌方行动构成每回合决策。
- 任务目标驱动移动和风险选择，而不只依赖消灭全部敌人。
- 基地中的队伍、成长、装备、奖励与商店会影响下一场战斗。
- 主线目标为 5 章、30 个任务和明确结局；该目标尚未完成，不能将数据条目视为可玩关卡。

## 首发范围约束

- 平台：Windows 桌面版。
- 模式：离线单人战役。
- 网络服务：仅作为开发、地图和可选 API 工具，不是运行必需条件。
- 关卡：使用经过校验并实际接入客户端的锁定地图；不以运行时随机地图替代正式内容。
- 资源：只使用可追溯、允许目标用途的 AI、程序化、自有或明确开源资源。

## 当前非目标

以下内容可以保留为未来探索，但不属于首发开发承诺：

- PvP、赛季、Battle Pass、公会或其他在线服务。
- 移动端发行。
- MOD、地图编辑器和 UGC 平台。
- Roguelike 独立模式。
- 载具、动态天气、日夜循环等会改变核心战斗范围的大型扩展。

## 设计决策原则

1. 一项机制必须有玩家可见的目标、反馈、失败条件和测试，才可以进入正式关卡。
2. 每个新章节只引入少量机制，并在之后的任务和 Boss 中复用、组合。
3. 美术与音频先制作少量真实小样，确认尺寸、透明、动画、性能和可读性后再批量生产。
4. 任何会扩大首发范围的提案先进入路线图评审，不直接写入完成状态。

较早的完整设计、扩展设想和参考资料见 [历史设计归档](../archive/design-notes/)。它们可能与本范围冲突，发生冲突时以本文件和路线图为准。
