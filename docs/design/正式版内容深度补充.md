## 1. Roguelike 模式（重玩核心）

### 1.1 模式概述

```
名称：深渊远征（Abyss Expedition）
定位：主线通关后的核心重玩模式
时长：每局 1-3 小时
特色：每次体验完全不同
```

### 1.2 流程

```
选择 4 人小队（从所有角色池）
  ↓
进入随机地图节点（Roguelike 地图）
  ↓
节点类型：战斗/商店/事件/休息/Boss/宝藏
  ↓
通关获得强化（三选一）
  ↓
深入下一层
  ↓
10 层后通关 / 全灭结束
  ↓
按层数结算奖励（带入主线）
```

### 1.3 节点类型（8 种）

| 节点 | 概率 | 内容 |
|------|------|------|
| 普通战斗 | 35% | 标准战斗 |
| 精英战斗 | 15% | 强敌战斗，奖励更好 |
| 商店 | 15% | 购买装备/物品/强化 |
| 事件 | 15% | 随机事件（选择有后果） |
| 休息 | 10% | 恢复 HP/解除负面/升级技能 |
| 宝藏 | 5% | 免费装备/物品 |
| 神秘 | 3% | 特殊遭遇（祭坛/许愿/诅咒） |
| Boss | 2% | 层 Boss（每 3 层 1 个） |

### 1.5 层数递进

| 层 | 敌人等级 | 特殊规则 |
|---|---------|---------|
| 1-3 | 1-5 | 基础 |
| 4-6 | 5-10 | +1 种地形 |
| 7-9 | 10-15 | +天气 |
| 10 | 15+ | 最终 Boss |

### 1.6 Roguelike 奖励

```
通关奖励（按层数）：
  层 1-3：信用点 200/层
  层 4-6：信用点 400/层 + 稀有装备
  层 7-9：信用点 600/层 + 史诗装备

失败奖励（按层数）：
  50% 通关奖励（不亏本，鼓励尝试）
```

## 5. 敌人行为树详细设计

### 5.1 通用行为树框架

```
Root
├── CheckAlarm (是否警觉)
│   ├── Yes → CombatBehavior
│   └── No → IdleBehavior
│
├── IdleBehavior
│   ├── Patrol (巡逻路线)
│   ├── Guard (守卫点位)
│   └── Investigate (调查声音)
│
├── CombatBehavior
│   ├── EvaluateThreat (评估威胁)
│   │   ├── LowThreat → AggressiveTactics
│   │   ├── MediumThreat → BalancedTactics
│   │   └── HighThreat → DefensiveTactics
│   │
│   ├── SelectTarget (选择目标)
│   │   ├── Priority: medic > low_hp > sniper > others
│   │   ├── Modify by: distance, cover, threat
│   │
│   ├── SelectAction (选择行动)
│   │   ├── CanKill → Attack
│   │   ├── CanFlank → Move + Attack
│   │   ├── UnderThreat → TakeCover
│   │   ├── LowHP → Retreat
│   │   └── SupportAlly → Buff/Heal
│   │
│   └── ExecuteAction
```

### 7.2 地形邻接规则

```yaml
adjacency_rules:
  water:
    adjacent_to: ["plain", "bridge"]  # 水域旁边只能是平地或桥
    not_adjacent_to: ["wall", "crate"]
  bridge:
    must_connect: ["water", "water"]  # 桥必须连接两片水
  highland:
    min_distance: 3  # 高地之间至少间隔3格
    max_cluster: 4   # 高地最多4格相连
  wall:
    max_linear: 5  # 墙最多连续5格
  poison:
    not_near_spawn: true  # 毒池不刷在出生区附近
```
