## 1. 天气与环境系统

### 1.1 天气类型（8 种）

| 天气 | 视觉效果 | 游戏影响 | 持续 | 出现章节 |
|------|---------|---------|------|---------|
| 晴天 | 明亮 | 无 | - | 全章节 |
| 雨天 | 雨滴、地面反光 | 命中-10%、视野-1、火焰无法扩散 | 3-5回合 | 2章+ |
| 雾天 | 浓雾遮蔽 | 视野-3、远程命中-20、潜行+1回合 | 2-4回合 | 3章+ |
| 雪天 | 飘雪、地面积雪 | 移动+1成本、火焰伤害-50%、冰面打滑 | 全场 | 4章+ |
| 沙尘暴 | 黄沙漫天 | 视野-2、远程命中-15、移动-1 | 3-6回合 | 特定地图 |
| 雷暴 | 闪电、雷声 | 每3回合随机1格雷击(40伤害)、电系技能+50% | 2-4回合 | 5章+ |
| 毒雾 | 绿色雾气 | 每回合全体-3%HP、解毒剂消耗×2 | 全场 | 3章+ |
| 极光 | 特殊光影 | 夜间视野+2、士气+10 | 全场 | 5章特殊 |

### 1.2 动态天气

```yaml
dynamic_weather:
  change_chance: 25%  # 每3回合检查一次
  forecast: "每关开始时预告本关可能天气"
  player_counter:
    - "天气控制装置(消耗品)：改变天气"
    - "狙击手技能'晴空'：清除雾/毒雾"
    - "侦察兵技能'风暴预警'：预知下次天气变化"
```

### 1.3 环境互动

| 环境物件 | 互动方式 | 效果 |
|---------|---------|------|
| 油桶 | 射击/爆炸 | 3×3燃烧2回合 |
| 变压器 | 射击 | 4×4电击区域，对机械×2伤害 |
| 水管 | 射击 | 生成水洼，电系技能扩散 |
| 天花板 | 破坏 | 坠落造成伤害+生成掩体碎片 |
| 通风口 | 进入 | 侦察兵专属，传送到另一出口 |
| 监控摄像头 | 黑客(侦察兵) | 揭示该区域敌人5回合 |
| 警报器 | 触发/关闭 | 触发→全图敌人警觉；关闭→恢复潜行 |
| 自动炮塔 | 黑客/破坏 | 黑客→转为友方3回合；破坏→爆炸 |
| 门/闸门 | 开关/破坏 | 改变地图通路 |
| 电梯 | 操作 | 改变高度层 |

## 2. 日夜循环系统

### 2.1 时段影响

| 时段 | 视野修正 | 命中修正 | 特殊 |
|------|---------|---------|------|
| 黎明 | -1 | -5 | 雾天概率高 |
| 白天 | 标准 | 标准 | - |
| 黄昏 | -1 | -5 | 侦察兵+1潜行 |
| 夜晚 | -3 | -10 | 侦察兵+2潜行、夜视仪消除惩罚 |

### 2.2 关卡内时段变化

```
某些关卡会随回合推进改变时段：
  回合1-4：夜晚（视野-3）
  回合5-8：黎明（视野-1）
  回合9+：白天（标准）

玩家需根据时段调整战术
```

### 2.3 夜间专属机制

| 机制 | 说明 |
|------|------|
| 手电筒 | 消耗品，使用时视野+2但暴露位置 |
| 夜视仪 | 头部装备，消除夜间惩罚 |
| 红外感应 | 侦察兵技能，3×3探测热源 |
| 暗影潜行 | 夜间潜行+1回合 |
| 照明弹 | 投掷物，5×5区域变为白天视野3回合 |

## 10. 角色羁绊与好感度

### 10.1 好感度系统

```
每个角色有好感度(0-100)
初始值：50
```

| 好感度等级 | 值 | 效果 |
|-----------|---|------|
| 冷淡 | 0-19 | 无特殊对话 |
| 普通 | 20-39 | 解锁基础对话 |
| 友好 | 40-59 | 组队+3%命中 |
| 信任 | 60-79 | 解锁深度对话+组队+5%命中 |
| 挚友 | 80-99 | 解锁专属任务+组队+8%命中+1士气 |
| 羁绊 | 100 | 解锁专属结局+组队+10%命中+永久不死(剧情) |

### 10.2 好感度提升方式

| 行为 | 好感度变化 |
|------|-----------|
| 同队出战 | +2/场 |
| 角色击杀保护 | +5 |
| 完成专属任务 | +15 |
| 赠送礼物 | +3~10 |
| 基地对话 | +1/次(每日1次) |
| 角色受伤未治疗 | -3 |
| 角色倒地 | -5 |
| 角色死亡(非经典模式) | -15 |

### 10.3 羁绊对话

每达到新好感度等级解锁对话（AI 生成），揭示角色背景故事。

### 10.4 专属任务

每个可招募角色有 1 个专属任务，好感度 60+ 解锁，完成后获得专属装备/技能。

## 13. 音效细节与环境互动

### 13.1 动态音效系统

| 场景 | 音效变化 |
|------|---------|
| 室内 | 回响大、脚步沉闷 |
| 室外 | 回响小、有环境音 |
| 雨天 | 雨声叠加、枪声被雨声掩盖 |
| 雾天 | 声音传播距离-1 |
| 夜晚 | 环境音降低、脚步更清晰 |
| 高地 | 风声 |
| 地下 | 回响最大 |

### 13.2 声音传播机制

```yaml
sound_propagation:

  enemy_reaction:
    - "听到声音的敌人会前往调查"
    - "侦察兵可利用声音诱敌"
```

### 13.3 音乐动态切换

```
战斗状态 → BGM
  ├── 潜行中：低调紧张音乐
  ├── 被发现：激烈战斗音乐
  ├── 优势明显：轻松音乐
  ├── 劣势明显：紧张音乐
  ├── Boss战：Boss专属音乐
  └── 胜利前夕：高潮音乐
```

## 14. 动态难度调整系统

### 14.1 隐形DDA（Dynamic Difficulty Adjustment）

```yaml
dda:
  enabled: "标准难度下默认开启"
  invisible: "玩家不知道，不显示"
  
  tracking:
    - "连胜次数"
    - "平均剩余HP%"
    - "平均通关回合数"
    - "单位阵亡次数"
    - "读档次数"
  
  adjustments:
    player_struggling:
      - "敌人命中-5%(隐形)"
      - "敌人AP恢复-1(偶尔)"
      - "掉落率+10%"
      - "增援延迟1回合"
    player_dominating:
      - "敌人命中+5%"
      - "敌人AP+1(偶尔)"
      - "增援提前1回合"
  
  limits:
    - "最多±10%调整"
    - "困难/残酷难度不触发DDA"
    - "PvP不触发DDA"
```
